# p28 고가물건(30억+) 관리 규칙 검수표 v1

대상 사건: 2024타경1001
법원: 서울중앙지방법원
주소: 서울시 예시구 예시동
아파트: 예시아파트
감정가: 3,200,000,000원
근거 라인 수: 2

## 1. 이 페이지에서 보는 것
- 30억이 넘는 물건이면 근거를 더 촘촘히 요구하는지 확인한다.
- 숫자 하나만 보고 고가물건으로 넘기지 않는지 본다.
- 근거 라인이 두 줄 이상 붙어 있는지 확인한다.

## 2. 입력 필드
- 감정가
- 근거 라인 수
- 사건번호
- 법원명
- 아파트명

## 3. 판정 순서
1. 감정가가 30억을 넘는지 본다.
2. 근거 라인 수를 확인한다.
3. 최소 2개 이상의 근거가 있는지 본다.
4. 원문과 OCR이 같은 사건 키인지 확인한다.

## 4. 통과 기준
- 감정가가 30억 초과다.
- 근거 라인이 2개 이상이다.
- 고가물건으로 분류할 이유가 남아 있다.

## 5. 보류 기준
- 30억 초과는 맞지만 근거가 하나뿐이면 HOLD.
- 숫자는 있으나 근거 라인 수가 흔들리면 HOLD.
- OCR이 감정가를 잘못 읽으면 HOLD.

## 6. 반려 기준
- 30억 초과인데 근거가 부족하면 DROP.
- 다른 사건 감정가를 가져오면 DROP.
- 근거 없이 고가물건 라벨만 붙이면 DROP.

## 7. 샘플 판정 예시
- GO: 감정가 32억 / 근거 라인 2개 / 고가물건 관리 필요
- HOLD: 31억이지만 근거 라인이 1개뿐인 경우
- DROP: 30억 초과인데 근거 없이 일반 물건처럼 처리한 경우

## 8. 기록할 것
- [p28] [GO/HOLD/DROP]
- 감정가
- 근거 라인 수
- 고가물건 여부
- 검수자/시각

## 9. 플랫폼에서 확인할 것
- UI는 감정가와 근거 라인 수를 같이 보여줘야 한다.
- 근거가 두 개 미만이면 완료 카드가 아니라 보류 카드로 보여야 한다.
- 30억 초과인데 일반 카드로 보이면 안 된다.
