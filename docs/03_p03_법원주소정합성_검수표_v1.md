# p03 법원/주소 정합성 검수표 v1

대상 사건: 2024타경1001
법원: 서울중앙지방법원
주소: 서울시 예시구 예시동
정합성 기준: 서울/수도권 아파트, 법원명과 주소 권역이 같은 사건으로 귀속되어야 한다.

## 1. 이 페이지에서 보는 것
- 법원명과 주소가 서로 같은 사건을 가리키는지 확인한다.
- 서울중앙지방법원인데 주소가 비수도권이면 즉시 이상징후로 본다.
- 같은 사건인데 법원명이나 주소가 다른 사건처럼 섞이면 안 된다.

## 2. 입력 필드
- 법원명 원문
- 주소 원문
- 시군구 토큰
- 아파트명
- 사건번호

## 3. 판정 순서
1. 법원명에서 관할 추정
2. 주소에서 시군구와 권역 추출
3. 서울/경기/인천 토큰 일치 여부 확인
4. 아파트명과 주소가 같은 단지인지 확인

## 4. 통과 기준
- 법원명과 주소 권역이 같다.
- 사건번호가 같은 사건으로 유지된다.
- 아파트명과 주소가 같은 단지로 읽힌다.
- 권역 확인 결과가 메모와 판정에 함께 남는다.

## 5. 보류 기준
- 주소는 보이는데 시군구가 잘려 있으면 HOLD.
- 법원명은 있는데 주소 권역이 불명확하면 HOLD.
- OCR이 서울/경기를 잘못 읽었을 가능성이 있으면 HOLD.
- 주소와 법원명이 서로 애매하면 DROP하지 말고 보완요청을 남긴다.

## 6. 반려 기준
- 서울/수도권이 아닌 사건이면 DROP.
- 법원명과 주소 권역이 끝내 맞지 않으면 DROP.
- 같은 사건번호가 다른 지역 사건과 섞이면 DROP.

## 7. 샘플 판정 예시
- GO: 서울중앙지방법원 / 서울시 예시구 예시동 / 예시아파트
- HOLD: 법원명은 서울중앙지방법원인데 주소가 '서울시'까지만 읽힌 경우
- DROP: 법원명은 서울중앙지방법원인데 주소가 부산/대구로 확정되는 경우

## 8. 기록할 것
- [p03] [GO/HOLD/DROP]
- 법원명 판정 결과
- 주소 권역 판정 결과
- 아파트명 일치 여부
- 보완 요청 필드
- 검수자/시각

## 9. 플랫폼에서 확인할 것
- UI는 p03 카드에서 법원명, 주소, 아파트명을 같은 사건 행으로 보여줘야 한다.
- 권역 불일치가 있으면 카드 아래에 보완 요청을 보여줘야 한다.
- p03이 HOLD면 다음 페이지는 검토만 가능하고 자동 승인하면 안 된다.

## 10. 다음 작업 기준
- p03 통과 후 p04 감정가 하한 필터로 넘어간다.
- 권역 불일치 케이스는 캡쳐 인식 보완 항목으로 넘긴다.
