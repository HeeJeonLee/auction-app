# p48 최종 취하 스크립트 조합 검수표 v1

대상 사건: 2024타경1001
제안유형: 취하 유도 최종안

## 1. 이 페이지에서 막는 것
- 판정만 있고 실행계획이 없는 최종안
- 수치 없이 문장만 많은 최종안
- 리스크와 완화수단이 분리된 채 제출되는 문서

## 2. 조합 순서
1. 판정요약: GO/HOLD/DROP 사유 1문장
2. 수치근거: 회수율/회수시점 2개
3. 리스크: 핵심 2개와 완화수단
4. 실행계획: 금액/기한/증빙

## 3. 길이 규정
- 본문 8~12문장
- 문장당 60자 내외
- 법률 확정 표현 금지

## 4. 통과 예시
- 판정 사유 1문장과 수치 2개가 먼저 제시됨
- 리스크 2개와 완화수단이 짝으로 제시됨
- 실행계획에 금액/기한/증빙이 모두 들어감

## 5. 검수 기준
- 수치가 없는 문장 비중 50% 초과 시 반려
- 실행계획 누락 시 HOLD
- 판정요약 누락 시 DROP

## 6. 판정 순서
1. 조합 순서 4단이 모두 있는지 본다.
2. 문장 수와 길이 규정을 본다.
3. 수치 문장 비중을 본다.
4. 실행계획 누락 여부를 본다.

## 7. 보류 기준
- 수치는 있는데 실행계획이 비면 HOLD.
- 리스크는 있는데 완화수단이 비면 HOLD.
- 문장 수가 규정을 벗어나면 HOLD.

## 8. 반려 조건
- 수치 없는 문장 비중 50% 초과.
- 판정요약 누락.
- 법률 확정 표현 사용.

## 9. UI 확인
- 4단 조합이 한 화면에 순서대로 보여야 한다.
- 수치 문장이 부족하면 자동 경고가 떠야 한다.
- 실행계획 누락 시 다운로드 버튼이 보류돼야 한다.
