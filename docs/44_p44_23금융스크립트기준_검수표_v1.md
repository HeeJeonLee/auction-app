# p44 2/3금융 스크립트 기준 검수표 v1

대상 사건: 2024타경1001
제안유형: 취하 유도 회수안

## 1. 이 페이지에서 막는 것
- 단일안만 던지는 스크립트
- 복구 경로가 없는 공격적 제안
- 회수속도와 실수익 중 하나만 보는 문구

## 2. 핵심 지표
- 회수소요기간 단축
- 순회수액 개선
- 실행 실패 시 복구 경로

## 3. 제안 방식
- 1안(보수), 2안(공격) 이중안으로 제시한다.
- 상대 반론이 강하면 1안을 우선 재제시한다.

## 4. 통과 예시
- 1안: 3개월 내 회수, 증빙 보수적으로 요구
- 2안: 1차 납입을 앞당겨 순회수액을 높이는 안
- 실패 시 즉시 복구 경로와 재접촉 제한을 적음

## 5. 판정 순서
1. 이중안이 있는지 본다.
2. 회수소요기간과 순회수액이 같이 적혔는지 본다.
3. 실패 시 복구 경로가 있는지 본다.
4. 셋 중 하나라도 비면 GO를 주지 않는다.

## 6. 보류 기준
- 1안만 있고 2안이 없으면 HOLD.
- 복구 경로는 있는데 재접촉 제한이 없으면 HOLD.
- 회수속도는 있는데 순회수액 비교가 없으면 HOLD.

## 7. 반려 조건
- 단일안만 제시.
- 복구 경로 누락.
- 실패 시 조치가 없는 공격안만 제시.

## 8. 검수 메모 예시
- [p44][HOLD] 이중안은 있으나 복구 경로 문구 부족.
- [p44][DROP] 단일안만 있고 실패 시 조치가 없음.

## 9. UI 확인
- 1안과 2안이 같은 화면에 보여야 한다.
- 복구 경로와 재접촉 제한이 별도 라인으로 보여야 한다.
- 실패 경로가 비면 발송 버튼이 비활성화돼야 한다.
