# p31 1차 판정 게이트 검수표 v1

대상 사건: 2024타경1001
법원: 서울중앙지방법원
주소: 서울시 예시구 예시동
아파트: 예시아파트
규칙점수: 78
규칙판정: HOLD

## 1. 이 페이지에서 보는 것
- 점수와 판정이 서로 맞는지 확인한다.
- 숫자만 높고 판정은 느슨한 경우를 막는다.
- 임계치가 문장으로도 설명되는지 본다.

## 2. 입력 필드
- 규칙점수
- 규칙판정
- 임계치
- 사건번호
- 규칙근거 문자열

## 3. 판정 순서
1. 규칙점수를 먼저 본다.
2. 판정이 GO/HOLD/DROP 중 무엇인지 확인한다.
3. 임계치와 판정이 맞는지 교차검증한다.
4. 근거 문자열이 점수와 판정을 받쳐 주는지 본다.

## 4. 통과 기준
- 점수와 판정이 서로 어긋나지 않는다.
- 임계치 기준이 문장으로 설명된다.
- 같은 사건 키에 점수와 판정이 붙는다.

## 5. 보류 기준
- 점수는 높지만 판정이 느슨하면 HOLD.
- 판정은 있는데 근거가 비면 HOLD.
- 임계치가 애매하면 HOLD.

## 6. 반려 기준
- 점수-판정 불일치면 DROP.
- 다른 사건 점수를 가져오면 DROP.
- 임계치보다 낮은데도 GO면 DROP.

## 7. 샘플 판정 예시
- GO: 92점 / GO / 임계치 충족
- HOLD: 78점 / HOLD / 보완 조건 필요
- DROP: 81점인데 GO로 저장한 경우

## 8. 기록할 것
- [p31] [GO/HOLD/DROP]
- 규칙점수
- 규칙판정
- 임계치
- 일치 여부
- 검수자/시각

## 9. 플랫폼에서 확인할 것
- UI는 점수와 판정을 같이 보여줘야 한다.
- 불일치가 있으면 완료 카드가 아니라 보류 카드여야 한다.
- 점수만 높다고 GO로 보이면 안 된다.
