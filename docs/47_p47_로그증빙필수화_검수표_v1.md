# p47 로그/증빙 필수화 검수표 v1

대상 사건: 2024타경1001
제안유형: 취하 유도 회수안

## 1. 이 페이지에서 막는 것
- 누가 결정했는지 추적되지 않는 기록
- 채널별 필수 증빙이 빠진 상태
- 다음 행동(next_action) 없는 종료 처리

## 2. 필수 로그 스키마
- case_id: 사건번호
- contact_at: 접촉 일시(로컬시간)
- channel: call/email/meeting
- counterparty: 상대 담당자/부서
- claim_summary: 핵심 주장 3줄 이내
- evidence_refs: 캡처/문서 파일명 목록
- next_action: 다음 행동과 마감시각

## 3. 필수 증빙 세트
- 통화: 통화요약 메모 + 확인 문자/메일
- 메일: 발신 원문 + 첨부 목록 + 수신확인
- 미팅: 참석자, 합의/보류 항목, 후속 일정

## 4. 통과 예시
- 채널별 필수 증빙이 모두 있고 next_action이 기한과 함께 기록됨
- claim_summary가 모호어가 아니라 수치/사실 중심으로 작성됨
- 증빙 파일명이 로그와 일치함

## 5. 반려 기준
- 채널별 필수 증빙 1개라도 누락
- next_action 미기록
- claim_summary가 모호어 중심으로만 작성됨

## 6. 보관 정책
- 최소 보관 24개월
- 수정 이력은 덮어쓰기 금지, append only
- 개인정보 마스킹 규칙 준수

## 7. 감사 추적
- 재검수 시 이전 버전 로그와 diff 자동 비교
- 판정 변경 시 변경자/변경시간/변경사유 필수 입력

## 8. 판정 순서
1. 로그 스키마 필드를 확인한다.
2. 채널별 증빙이 있는지 확인한다.
3. next_action과 마감시각이 있는지 확인한다.
4. 누락이 있으면 GO를 주지 않는다.

## 9. UI 확인
- 로그 필드와 증빙 링크가 같은 화면에 보여야 한다.
- 필수 증빙 누락 시 즉시 보류 알림이 떠야 한다.
- next_action이 비면 완료 버튼을 막아야 한다.

## 10. 다음 작업
