# p42 공공/조세채권 제한사항 검수표 v1

대상 사건: 2024타경1001
제안유형: 취하 유도 회수안

## 1. 이 페이지에서 막는 것
- 공공채권에 규정 밖 감면을 약속하는 문구
- 근거 없이 납기와 기한을 단축한다고 쓰는 문구
- 내부결재가 필요한데도 발송부터 하는 상태

## 2. 제한 체크
- 감면 가능 여부
- 분납 허용 범위
- 내부결재 단계와 소요기간

## 3. 통과 예시
- 가능 검토 범위 내에서만 감면안을 제시함
- 분납 허용 범위를 내부결재 기준에 맞춰 적음
- 법무 검토 1회 완료 후 발송 대기

## 4. 판정 순서
1. 감면 가능 여부가 확인됐는지 본다.
2. 분납 허용 범위가 적혀 있는지 본다.
3. 내부결재 단계와 소요기간이 적혀 있는지 본다.
4. 셋 중 하나라도 비면 GO를 주지 않는다.

## 5. 보류 기준
- 감면 여부는 있는데 범위가 없으면 HOLD.
- 분납은 있는데 내부결재 단계가 없으면 HOLD.
- 법무 검토 전이면 HOLD.

## 6. 반려 조건
- 규정 밖 감면 약속.
- 근거 없는 기한 단축 보장.
- 검토 없이 확정 표현 사용.

## 7. 검수 메모 예시
- [p42][HOLD] 감면 가능 여부는 있으나 내부결재 단계 누락.
- [p42][DROP] 규정 밖 감면 약속 문구 발견.

## 8. UI 확인
- 감면 가능 여부, 분납 범위, 내부결재 단계가 같은 화면에 보여야 한다.
- 법무 검토 전이면 발송 버튼이 비활성화돼야 한다.
- "가능 검토"가 아니라 "확정"으로 보이면 보류해야 한다.

## 9. 기록할 것
- 감면 가능 여부
- 분납 허용 범위
- 내부결재 단계
- 소요기간
- 법무 검토 여부
