# p38 회수시점 개선 문구 검수표 v1

대상 사건: 2024타경1001
제안유형: 취하 유도 회수안

## 1. 이 페이지에서 막는 것
- 금액만 있고 시간가치가 없는 제안문
- "빠르게" 같은 모호어만 있는 제안문
- 실패 시 복귀 절차가 빠진 제안문

## 2. 작성 원칙
- 첫 문장에 회수시점 단축 수치를 넣는다.
- 두 번째 문장에 이행일정과 증빙 제출일을 넣는다.
- 세 번째 문장에 실패 시 복귀 절차를 넣는다.

## 3. 통과 예시
- 경매 지속 대비 회수 시점을 3.2개월 단축합니다.
- 1차 납입은 14일 내 실행하고, 완납 일정은 별첨 캘린더로 제출합니다.
- 미이행 시 즉시 경매 절차로 복귀합니다.

## 4. 판정 순서
1. 회수시점 수치가 있는지 본다.
2. 날짜가 아니라 문장으로만 뭉개지지 않았는지 본다.
3. 실패 시 복귀 절차가 빠지지 않았는지 본다.
4. 셋 중 하나라도 비면 GO를 주지 않는다.

## 5. 보류 기준
- 단축 수치가 있는데 기준 비교가 없으면 HOLD.
- 납입일은 있는데 증빙 제출일이 없으면 HOLD.
- 복귀 절차는 있는데 책임자가 없으면 HOLD.

## 6. 반려 기준
- 추정치 없이 "빠르게"만 쓰면 DROP.
- 상대 비난 표현이 있으면 DROP.
- 법률 확정 판단처럼 보이면 DROP.

## 7. 검수 메모 예시
- [p38][HOLD] 회수시점 수치는 있으나 복귀 절차 문구 누락.
- [p38][DROP] "빠르게 정리"만 있고 수치와 일정이 없음.

## 8. UI 확인
- 회수시점 수치와 일정이 같은 카드에 보여야 한다.
- 미이행 시 복귀 절차는 별도 강조로 보여야 한다.
- 모호어가 보이면 발송 전 보류 상태가 떠야 한다.

## 9. 기록할 것
- 회수시점 단축 수치
- 1차 납입일
- 완납일
- 증빙 제출일
- 복귀 절차 문구
