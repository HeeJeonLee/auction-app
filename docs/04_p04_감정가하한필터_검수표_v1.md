# p04 감정가 하한 필터 검수표 v1

대상 사건: 2024타경1001
감정가: 1,000,000,000원
하한 기준: 500,000,000원

## 1. 이 페이지에서 보는 것
- 감정가가 5억 이상인지 확인한다.
- 금액 단위가 원인지 만원인지 혼동되지 않았는지 확인한다.
- 하한 미달 사건을 적격으로 잘못 올리지 않았는지 확인한다.

## 2. 입력 필드
- 감정가 원문
- OCR 감정가
- 금액 단위
- 최저매각가격
- 부채총액

## 3. 판정 순서
1. 감정가 숫자만 먼저 읽는다.
2. 원/만원 단위를 확인한다.
3. 5억 하한과 비교한다.
4. 최저매각가격과 부채총액이 감정가보다 과도하게 튀지 않는지 본다.

## 4. 통과 기준
- 감정가가 5억 이상이다.
- 금액 단위가 원으로 확정된다.
- 감정가와 최저매각가격이 수치상 맞는다.
- 부채총액이 감정가를 넘더라도 그 사실이 메모에 남는다.

## 5. 보류 기준
- 감정가 단위가 원/만원으로 헷갈리면 HOLD.
- OCR 숫자 일부가 잘려 있으면 HOLD.
- 5억 근처인데 자리수가 불명확하면 HOLD.

## 6. 반려 기준
- 감정가가 5억 미만이면 DROP.
- 감정가가 아예 읽히지 않으면 DROP.
- 단위 오류를 끝내 정정하지 못하면 DROP.

## 7. 샘플 판정 예시
- GO: 1,000,000,000원
- HOLD: 500,000,000원 근처인데 OCR이 50,000,000원으로 흔들리는 경우
- DROP: 300,000,000원처럼 하한 미달이 확정된 경우

## 8. 기록할 것
- [p04] [GO/HOLD/DROP]
- 감정가 원문
- OCR 감정가
- 단위 확인 결과
- 보완 요청 필드
- 검수자/시각

## 9. 플랫폼에서 확인할 것
- UI는 p04 카드에 감정가와 최저매각가격을 같은 행으로 보여줘야 한다.
- 하한 미달이면 적격 카드가 아니라 보류/제외로 보여야 한다.
- 금액 단위가 불명확하면 자동 승인하면 안 된다.

## 10. 다음 작업 기준

- 단위 혼동이 많으면 캡쳐 인식 보완 규칙으로 넘긴다.
