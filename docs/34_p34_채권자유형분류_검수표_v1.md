# p34 채권자 유형 분류 검수표 v1

대상 사건: 2024타경1001
법원: 서울중앙지방법원
주소: 서울시 예시구 예시동
아파트: 예시아파트
주요채권자: 서울은행
채권자 유형: 1금융

## 1. 이 페이지에서 보는 것
- 채권자 이름만 보고도 대충 분류하지 않았는지 확인한다.
- 은행, 캐피탈, 유동화, 공공기관이 섞일 때 잘못 찍지 않는지 본다.
- 분류가 곧 협상 프레임으로 이어질 수 있는지 확인한다.

## 2. 입력 필드
- 주요채권자
- 채권자 유형
- 사건번호
- 담당자메모
- 기본 스크립트

## 3. 판정 순서
1. 상호에서 은행/농협/수협/중앙회 같은 단서를 본다.
2. 저축/캐피탈/대부/파이낸셜이면 2/3금융으로 본다.
3. 유동화/NPL/자산관리면 유동화 계열로 본다.
4. 세무서/구청/시청/건강보험이면 공공으로 본다.

## 4. 통과 기준
- 채권자명과 유형이 서로 맞는다.
- 유형별로 기본 스크립트가 달라진다.
- 담당자메모가 분류 근거를 적고 있다.

## 5. 보류 기준
- 상호에 은행과 캐피탈 단서가 같이 있으면 HOLD.
- 약어만 있고 사업자등록명이 안 보이면 HOLD.
- 유형이 맞는지 확정 못 하면 HOLD.

## 6. 반려 기준
- 유형 오분류가 명확하면 DROP.
- 다른 사건 채권자 유형을 가져오면 DROP.
- 유형 없이 기본 스크립트를 바로 내면 DROP.

## 7. 샘플 판정 예시
- GO: 서울은행 / 1금융 / 기본 스크립트 1안은 은행용
- HOLD: 상호에 은행과 캐피탈 표기가 함께 보여 재확인이 필요한 경우
- DROP: 대부업체를 1금융으로 둔 경우

## 8. 기록할 것
- [p34] [GO/HOLD/DROP]
- 주요채권자
- 채권자 유형
- 기본 스크립트
- 오분류 위험도
- 검수자/시각

## 9. 플랫폼에서 확인할 것
- UI는 채권자명과 유형을 같이 보여줘야 한다.
- 유형이 애매하면 기본 스크립트를 내지 말아야 한다.
- 오분류 위험도가 높으면 보류 카드로 보여야 한다.
