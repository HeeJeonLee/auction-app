## 1. 경매 핵심 법규

### 1.1 민사집행법 (핵심 조항)

#### 제91조 (매각물의 인수주의)
```
매수인은 다음 각 호의 권리와 부담을 인수하여야 한다.
1. 최선순위 전세권
2. 말소기준권리보다 선순위인 임차권
3. 지상권, 지역권
4. 법정지상권
```

**실무 해석:**
- 말소기준권리보다 **앞선** 권리는 인수해야 함
- 말소기준권리보다 **뒤** 권리는 매각으로 소멸
- **이것이 경매의 핵심!**

#### 제144조 (배당요구)
```
이해관계인은 배당요구 종기까지 배당요구를 할 수 있다.
임차인이 대항력과 우선변제권을 갖춘 경우, 배당요구를 하지 않아도 배당받을 수 있다.
```

**실무 포인트:**
- 확정일자 + 대항력 = 자동 배당
- 배당요구 안해도 선순위면 배당받음
- **임차인이 가장 무서운 이유**

### 1.2 주택임대차보호법 (최중요)

#### 제3조 (대항력의 취득)
```
대항요건을 갖춘 임차인은 다음 날부터 대항력을 가진다.
1. 주택의 인도 (전입신고)
2. 주민등록 (전입일자)
```

#### 제3조의2 (임차권등기명령)
```
보증금 미반환 시 임차권등기명령을 신청할 수 있다.
임차권등기를 하면 대항력과 우선변제권이 유지된다.
```

**실무 판단 기준:**
```
선순위 임차인 판단 순서:
1. 전입일자 확인
2. 말소기준권리 일자와 비교
3. 전입일자 < 말소기준권리 → 선순위 (인수 필수!)
4. 전입일자 > 말소기준권리 → 후순위 (소멸)
```

#### 제8조 (우선변제권)
```
임차인이 다음을 갖추면 우선변제를 받을 수 있다.
1. 대항요건 (전입 + 점유)
2. 확정일자
3. 배당요구 (대항력 있으면 불필요)

단, 소액임차인은 보증금 일정액까지 최우선으로 변제받는다.
```

**지역별 소액임차인 보호 한도 (2026년 기준 추정):**
| 지역 | 보증금 범위 | 최우선변제 한도 |
|------|-------------|-----------------|
| 서울 | 1억6천만원 이하 | 5,500만원 |
| 수도권 | 1억3천만원 이하 | 4,500만원 |
| 광역시 | 1억원 이하 | 3,800만원 |
| 기타 | 8천만원 이하 | 3,000만원 |

**실무 치명도:**
- 소액임차인 1명만 있어도 **최소 3천만원~5,500만원 손실**
- 대항력 확인 안하면 **낙찰 후 거액 손실**

## 2. 말소기준권리 판단 (경매의 핵심 중 핵심)

### 2.1 말소기준권리란?

**정의:**
경매로 인해 소멸하는 권리와 존속하는 권리를 구분하는 **시간적 기준점**

**종류 (우선순위):**
1. **경매개시결정 등기** ← 가장 흔함
2. **가장 빠른 가압류** (경매개시결정보다 앞서면)
3. **가장 빠른 압류**
4. **담보권 실행을 위한 경매개시결정**

### 2.2 실무 판단 프로세스

```python
# 말소기준권리 자동 판단 알고리즘
def determine_erasure_standard(rights_data):
    """
    등기부등본의 권리들을 날짜순으로 정렬하여
    말소기준권리를 자동 판단
    """
    candidates = []
    
    # 1. 경매개시결정 등기 찾기
    for right in rights_data:
        if right['type'] == '경매개시결정':
            candidates.append({
                'type': '경매개시결정',
                'date': right['registration_date'],
                'priority': 1
            })
    
    # 2. 가압류 중 가장 빠른 것
    seizures = [r for r in rights_data if r['type'] == '가압류']
    if seizures:
        earliest = min(seizures, key=lambda x: x['date'])
        candidates.append({
            'type': '가압류',
            'date': earliest['date'],
            'priority': 2
        })
    
    # 3. 가장 빠른 것 선택
    if candidates:
        erasure = min(candidates, key=lambda x: (x['priority'], x['date']))
        return erasure
    
    return None
```

**실제 사례:**

```
사건: 2024타경12345
등기부 을구 현황:

순위  |  등기목적      | 접수일자    | 권리자
1     | 근저당설정    | 2020.03.15 | ○○은행
2     | 근저당설정    | 2021.05.20 | △△저축은행
3     | 가압류        | 2023.08.10 | 개인채권자 홍길동
4     | 경매개시결정  | 2024.01.15 | 서울중앙지법
5     | 가압류        | 2024.03.20 | 세무서

→ 말소기준권리: 순위3번 가압류 (2023.08.10)
   ∵ 경매개시결정보다 빠른 가압류가 존재
   
→ 소멸: 순위4번 이후 (경매개시결정, 후순위 가압류)
→ 존속: 순위1~3번 (근저당 2건, 가압류 1건)
```

### 2.3 치명적 실수 사례

❌ **잘못된 판단:**
```
"경매개시결정이 2024.01.15이니까
이 날짜가 말소기준권리다!"
```

✅ **올바른 판단:**
```
"2023.08.10 가압류가 더 앞서 있으므로
이것이 말소기준권리다!
따라서 2021년 근저당도 인수해야 한다!"
```

**손실액 차이:**
- 잘못 판단: 근저당 5억 인수 못함 → **5억 손해**
- 올바른 판단: 사전에 확인 → 입찰 포기 or 가격 조정

## 3. 선순위 임차인 대항력 (가장 치명적)

### 3.1 대항력 발생 시점

```
대항력 발생 = 다음 날 00시

전입일자: 2023.05.09
대항력 발생: 2023.05.10 00:00

따라서:
- 말소기준권리 2023.05.09 → 임차인이 후순위 (소멸)
- 말소기준권리 2023.05.10 → 임차인이 선순위 (인수!)
- 말소기준권리 2023.05.11 → 임차인이 선순위 (인수!)
```

**1일 차이로 수천만원~수억 손실 발생!**

### 3.2 우선변제권 vs 대항력

| 구분 | 대항력만 | 대항력 + 확정일자 |
|------|----------|-------------------|
| 전입신고 | ✅ 필수 | ✅ 필수 |
| 확정일자 | ❌ 없음 | ✅ 필수 |
| 낙찰 후 | 인수해야 함 | 배당 + 인수 |
| 치명도 | ★★★★☆ | ★★★★★ (최악) |

**실무 시나리오:**

```
【케이스 A: 대항력만 있는 임차인】
- 전입일자: 2023.03.01 (말소기준권리보다 앞)
- 확정일자: 없음
- 보증금: 2억

→ 결과: 
  낙찰자가 2억 보증금 인수
  임차인은 계속 거주 가능
  명도 불가능
  
→ 치명도: ★★★★☆
  실질 낙찰가 = 입찰가 + 2억


【케이스 B: 대항력 + 확정일자】
- 전입일자: 2023.03.01 (말소기준권리보다 앞)
- 확정일자: 2023.03.05
- 보증금: 2억

→ 결과:
  배당에서 2억 우선 배당
  + 낙찰자가 잔여 보증금 인수 (있다면)
  
→ 치명도: ★★★★★ (최악)
  채권자 배당액 ↓↓↓
  경매취하 협상 극도로 어려움
```

### 3.3 소액임차인 (핵폭탄급)

**최우선변제권:**
```
서울: 보증금 1.6억 이하 → 5,500만원 최우선
경기: 보증금 1.3억 이하 → 4,500만원 최우선

조건:
1. 대항력 있을 것
2. 경매신청 등기 전 대항력 취득
3. 배당요구불요 (자동 배당)
```

**실제 사례:**
```
낙찰가: 5억
선순위 근저당: 4억
소액임차인: 보증금 1억 (전입: 2020.01.01)
  → 최우선변제: 5,500만원

배당순서:
1. 소액임차인: 5,500만원 (최우선)
2. 집행비용: 500만원
3. 선순위 근저당: 4억
4. 나머지 채권자: 0원

→ 배당 부족액: 5,500만 + 500만 + 4억 = 5억원
→ 실제 배당 가능액: 5억 - 비용 = 4.95억
→ 근저당 배당: 3.95억만 배당 (5천만원 손실)
```

**경매취하 영향:**
- 채권자가 배당으로 받을 돈 ↓↓↓
- 협상 여지 ↑↑↑
- 소액임차인 있으면 **협상 가능성 급상승**

## 4. 배당표 작성 실무

### 4.1 배당 순서 (절대 법칙)

```
1순위: 경매 집행비용 (약 1~2%)
2순위: 소액임차인 최우선변제
3순위: 당해세 (최종 3년치)
4순위: 선순위 근저당/전세권
5순위: 임차인 우선변제권 (확정일자)
6순위: 일반 채권
7순위: 후순위 근저당
8순위: 잉여금 (소유자)
```

### 4.2 배당표 시뮬레이션 엔진

```python
def simulate_dividend_table(case_info):
    """
    실전 배당표 시뮬레이션
    """
    bid_price = case_info['낙찰가']
    
    # 1. 집행비용 (약 1.5%)
    execution_cost = bid_price * 0.015
    remaining = bid_price - execution_cost
    
    dividends = [{
        'rank': 1,
        'creditor': '집행비용',
        'claim': execution_cost,
        'dividend': execution_cost,
        'rate': 100.0
    }]
    
    # 2. 소액임차인 최우선변제
    for tenant in case_info.get('소액임차인', []):
        if tenant['대항력'] and tenant['전입일자'] < case_info['경매신청일']:
            priority_amount = min(
                tenant['보증금'],
                get_priority_limit(case_info['지역'])  # 5,500만원 등
            )
            actual = min(priority_amount, remaining)
            remaining -= actual
            
            dividends.append({
                'rank': 2,
                'creditor': f"소액임차인 {tenant['이름']}",
                'claim': priority_amount,
                'dividend': actual,
                'rate': (actual / priority_amount * 100) if priority_amount > 0 else 0
            })
    
    # 3. 당해세 (재산세, 종부세 최근 3년)
    taxes = case_info.get('당해세', 0)
    actual_tax = min(taxes, remaining)
    remaining -= actual_tax
    
    dividends.append({
        'rank': 3,
        'creditor': '당해세',
        'claim': taxes,
        'dividend': actual_tax,
        'rate': (actual_tax / taxes * 100) if taxes > 0 else 0
    })
    
    # 4. 선순위 근저당
    senior_claims = []
    for mortgage in case_info.get('근저당', []):
        if mortgage['등기일자'] < case_info['말소기준권리일자']:
            senior_claims.append({
                'creditor': mortgage['채권자'],
                'amount': mortgage['채권최고액'],
                'date': mortgage['등기일자']
            })
    
    # 날짜순 정렬
    senior_claims.sort(key=lambda x: x['date'])
    
    for claim in senior_claims:
        actual = min(claim['amount'], remaining)
        remaining -= actual
        
        dividends.append({
            'rank': 4,
            'creditor': claim['creditor'],
            'claim': claim['amount'],
            'dividend': actual,
            'rate': (actual / claim['amount'] * 100)
        })
    
    # 5. 선순위 임차인 (확정일자)
    for tenant in case_info.get('임차인', []):
        if (tenant.get('확정일자') and 
            tenant['전입일자'] < case_info['말소기준권리일자']):
            
            # 소액임차인으로 이미 최우선 받았으면 잔액만
            priority_received = tenant.get('최우선변제액', 0)
            remaining_deposit = tenant['보증금'] - priority_received
            
            if remaining_deposit > 0:
                actual = min(remaining_deposit, remaining)
                remaining -= actual
                
                dividends.append({
                    'rank': 5,
                    'creditor': f"임차인 {tenant['이름']}",
                    'claim': remaining_deposit,
                    'dividend': actual,
                    'rate': (actual / remaining_deposit * 100)
                })
    
    # 6. 일반채권 (가압류 등)
    for seizure in case_info.get('가압류', []):
        if seizure['등기일자'] < case_info['말소기준권리일자']:
            actual = min(seizure['청구금액'], remaining)
            remaining -= actual
            
            dividends.append({
                'rank': 6,
                'creditor': seizure['채권자'],
                'claim': seizure['청구금액'],
                'dividend': actual,
                'rate': (actual / seizure['청구금액'] * 100)
            })
    
    # 7. 잉여금 (있다면 소유자)
    if remaining > 0:
        dividends.append({
            'rank': 8,
            'creditor': '소유자 (잉여금)',
            'claim': remaining,
            'dividend': remaining,
            'rate': 100.0
        })
    
    return {
        'dividends': dividends,
        'total_claim': sum(d['claim'] for d in dividends),
        'total_dividend': bid_price,
        'shortage': sum(max(0, d['claim'] - d['dividend']) for d in dividends)
    }
```

### 4.3 실전 사례

```
【서울 강남구 아파트】

낙찰예상가: 7.68억 (64%)

권리관계:
1. 근저당 (2020.01): 5억 (○○은행)
2. 임차인 (2021.03): 2억 (확정일자 O, 소액 X)

→ 배당 시뮬레이션 (낙찰가 7.68억):

순위 | 채권자 | 청구액 | 배당액 | 배당률
-----|--------|--------|--------|-------
1 | 집행비용 | 1,152만 | 1,152만 | 100%
2 | 당해세 | 300만 | 300만 | 100%
3 | 근저당 (은행) | 5억 | 5억 | 100%
4 | 임차인 | 2억 | 2.53억 | 126.5%

→ 총 배당가능액: 7.68억

  - 당해세: 300만
  - 근저당: 5억

→ 부족액: 5.53억 - 5억 = 5,300만원

→ 가압류 채권자: 배당 0원!

→ 경매취하 협상:
  가압류 채권자 입장: "1억 받을 거 0원"
  → 할인 협상 가능성 ↑↑↑
  
  은행 입장: "5억 전액 회수 가능"
  → 협상 여지 거의 없음
```

## 5. 경매취하 조건

###5.1 법적 요건

**민사집행법 제263조 (경매취하)**
```
최고가매수신고 전까지 경매신청을 취하할 수 있다.
단, 다음의 경우 이해관계인의 동의가 필요하다:
1. 다른 채권자가 배당요구를 한 경우
2. 압류채권자가 있는 경우
```

**실무 절차:**
```
1. 모든 채권자 동의 필요
2. 채무 전액 변제 증명 OR
3. 채권자와 합의서 작성
4. 법원에 취하서 제출
5. 등기부 정리 (압류/가압류 말소)
```

### 5.2 취하 필요 자금 계산

```python
def calculate_withdrawal_funds(case_info, strategy='conservative'):
    """
    경매취하 필요자금 계산
    
    strategy:
      - conservative: 100% 변제 (안전)
      - negotiation: 할인 협상 (80~90%)
      - aggressive: 대폭 할인 (60~80%)
    """
    funds_needed = {
        '집행비용': 0,
        '선순위채권': 0,
        '배당요구채권': 0,
        '협상비용': 0,
        '예비비': 0
    }
    
    # 1. 집행비용 (이미 발생한 것)
    if case_info.get('경매진행단계') in ['유찰1회', '유찰2회', '유찰3회']:
        funds_needed['집행비용'] = case_info['감정가'] * 0.01
    
    # 2. 선순위 채권 (근저당 등)
    for mortgage in case_info.get('근저당', []):
        if mortgage['등기일자'] < case_info['말소기준권리일자']:
            # 원금 + 이자 추정
            principal = mortgage['채권최고액'] * 0.7  # 보통 채권최고액의 70%
            years = (datetime.now().year - mortgage['설정연도'])
            interest = principal * mortgage.get('금리', 0.05) * years
            
            funds_needed['선순위채권'] += principal + interest
    
    # 3. 배당요구 채권
    for creditor in case_info.get('배당요구채권자', []):
        claim_amount = creditor['청구금액']
        
        # 채권자 유형별 할인율
        if strategy == 'conservative':
            discount = 1.0
        elif strategy == 'negotiation':
            if '유동화' in creditor['이름'] or 'NPL' in creditor['이름']:
                discount = 0.7  # NPL펀드는 30% 할인 가능
            elif '은행' in creditor['이름']:
                discount = 0.95  # 은행은 5% 할인
            else:
                discount = 0.85  # 일반 채권자 15% 할인
        else:  # aggressive
            if '유동화' in creditor['이름']:
                discount = 0.6
            elif '은행' in creditor['이름']:
                discount = 0.9
            else:
                discount = 0.7
        
        funds_needed['배당요구채권'] += claim_amount * discount
    
    # 4. 임차인 (선순위는 반드시 변제)
    for tenant in case_info.get('임차인', []):
        if tenant['전입일자'] < case_info['말소기준권리일자']:
            funds_needed['선순위채권'] += tenant['보증금']
    
    # 5. 협상비용 (법무사, 등기비용 등)
    funds_needed['협상비용'] = funds_needed['선순위채권'] * 0.02
    
    # 6. 예비비 (5%)
    subtotal = sum(funds_needed.values())
    funds_needed['예비비'] = subtotal * 0.05
    
    total = sum(funds_needed.values())
    
    return {
        'breakdown': funds_needed,
        'total': total,
        'strategy': strategy,
        'feasibility': assess_feasibility(case_info, total)
    }

def assess_feasibility(case_info, required_funds):
    """취하 가능성 평가"""
    property_value = case_info.get('KB시세', case_info['감정가'])
    ltv = (required_funds / property_value) * 100
    
    if ltv < 60:
        return '매우 높음 (금융권 대출 가능)'
    elif ltv < 75:
        return '높음 (2금융 대출 가능)'
    elif ltv < 85:
        return '보통 (대부업 검토 가능)'
    elif ltv < 100:
        return '낮음 (자기자본 필요)'
    else:
        return '불가능 (부채초과)'
```

```python
def estimate_eviction_cost(case_info):
    """명도비용 추정"""
    cost = {
        '임차인이사비': 0,
        '소송비용': 0,
        '강제집행비': 0,
        '시간가치손실': 0
    }
    
    # 선순위 임차인
    senior_tenants = [t for t in case_info.get('임차인', [])
                     if t['전입일자'] < case_info['말소기준권리일자']]
    
    if senior_tenants:
        # 보증금 전액 + 이사비
        for t in senior_tenants:
            cost['임차인이사비'] = t['보증금'] + 300만원
    
    # 후순위 임차인/점유자
    junior_occupants = [t for t in case_info.get('임차인', [])
                       if t['전입일자'] >= case_info['말소기준권리일자']]
    
    if junior_occupants:
        cost['임차인이사비'] += len(junior_occupants) * 500만원
        cost['소송비용'] = 300만원
        cost['강제집행비'] = 200만원
    
    # 유치권 주장 가능성
    if case_info.get('유치권위험', False):
        cost['소송비용'] += 1000만원
        cost['시간가치손실'] = case_info['감정가'] * 0.01 * 6  # 6개월 금리
    
    return cost
```

### 7.2 유찰 횟수별 영향

```python
def assess_auction_interest(region, fail_count, appraisal_price):
    """
    지역과 유찰 횟수로 시장 관심도 평가
    """
    base_rate = {
        '강남3구': 0.85,
        '서울기타': 0.78,
        '경기신도시': 0.75,
        '경기기타': 0.70,
        '인천': 0.68
    }.get(region, 0.65)
    
    # 유찰마다 5~7% 하락
    drop_rate = 0.06
    current_rate = base_rate * (1 - drop_rate) ** (fail_count - 1)
    
    # 고가 물건은 더 큰 하락
    if appraisal_price > 15억:
        current_rate *= 0.95
    elif appraisal_price > 30억:
        current_rate *= 0.90
    
    if current_rate < 0.50:
        interest = '매우 낮음 (경매취하 협상 최적)'
    elif current_rate < 0.65:
        interest = '낮음 (협상 유리)'
    elif current_rate < 0.75:
        interest = '보통'
    else:
        interest = '높음 (협상 불리)'
    
    return {
        'expected_rate': current_rate,
        'market_interest': interest,
        'withdrawal_opportunity': current_rate < 0.65
    }
```
