# p11 매각기일/잔여일수 신뢰성 검증 검수표 v1

대상 사건: 2024타경1001
법원: 서울중앙지방법원
주소: 서울시 예시구 예시동
아파트: 예시아파트
매각기일 원문: 2026-08-27
파싱값: 2026-08-27
잔여일수: 17

## 1. 이 페이지에서 보는 것
- 매각기일이 날짜로 안정적으로 읽히는지 확인한다.
- 잔여일수를 다시 계산했을 때 같은 값이 나오는지 본다.
- 음수 날짜나 미확정 상태가 섞이지 않았는지 본다.

## 2. 입력 필드
- 매각기일 원문
- 파싱값
- 잔여일수
- 기준일
- 사건번호

## 3. 판정 순서
1. 매각기일 원문을 먼저 확인한다.
2. 파싱값이 같은 날짜인지 본다.
3. 기준일로 잔여일수를 재계산한다.
4. 음수 또는 비정상 값이 없는지 확인한다.

## 4. 통과 기준
- 매각기일이 날짜 형식으로 확정된다.
- 잔여일수가 재계산 값과 일치한다.
- 원문과 파싱값이 같은 사건 키로 묶인다.

## 5. 보류 기준
- 날짜는 읽혔지만 잔여일수 계산이 흔들리면 HOLD.
- 기준일이 없으면 HOLD.
- 원문과 파싱값이 다르면 HOLD.

## 6. 반려 기준
- 날짜 미확정 상태인데 GO면 DROP.
- 잔여일수가 음수인데 통과시키면 DROP.
- 다른 사건의 기일을 가져왔으면 DROP.

## 7. 샘플 판정 예시
- GO: 2026-08-27 / 잔여일수 17 / 정상 일치
- HOLD: 날짜는 보이지만 기준일이 없어 잔여일수 계산이 불안정한 경우
- DROP: 파싱값이 다른 날짜로 읽힌 경우

## 8. 기록할 것
- [p11] [GO/HOLD/DROP]
- 매각기일 원문
- 파싱값
- 잔여일수 재계산 결과
- 검수자/시각

## 9. 플랫폼에서 확인할 것
- UI는 원문 날짜, 파싱값, 잔여일수를 같이 보여줘야 한다.
- 잔여일수 음수면 자동 승인하지 말고 보류로 내려야 한다.
- 날짜 미확정 상태를 승인 카드로 보여주면 안 된다.
