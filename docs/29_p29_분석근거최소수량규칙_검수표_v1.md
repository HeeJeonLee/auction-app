# p29 분석근거 최소 수량 규칙 검수표 v1

대상 사건: 2024타경1001
법원: 서울중앙지방법원
주소: 서울시 예시구 예시동
아파트: 예시아파트
evidence 라인: 3개
최소 기준: 2개

## 1. 이 페이지에서 보는 것
- 근거 라인이 충분한지 확인한다.
- 숫자 하나만 달랑 있는 결론을 막는다.
- 근거가 모자라면 보완 요청으로 넘긴다.

## 2. 입력 필드
- evidence 라인
- 최소 기준
- 사건번호
- 법원명
- 검수 메모

## 3. 판정 순서
1. evidence 라인을 센다.
2. 최소 기준과 비교한다.
3. 미달이면 보완 요청이 필요한지 본다.
4. 원문과 OCR이 같은 사건 키인지 확인한다.

## 4. 통과 기준
- evidence 라인이 최소 기준 이상이다.
- 근거가 실제로 읽을 수 있다.
- 결론이 근거 위에 올라간다.

## 5. 보류 기준
- 근거는 있으나 기준 미달이면 HOLD.
- 라인 수는 맞지만 내용이 비면 HOLD.
- OCR이 일부 근거를 빼먹으면 HOLD.

## 6. 반려 기준
- 근거 부족인데 GO면 DROP.
- 다른 사건의 근거 라인을 섞으면 DROP.
- 최소 기준을 못 채웠는데 완료 처리하면 DROP.

## 7. 샘플 판정 예시
- GO: evidence 3개 / 최소 기준 2개 / 기준 충족
- HOLD: evidence 1개 / 최소 기준 미달 / 보완 요청 필요
- DROP: 근거 없이 결과만 남긴 경우

## 8. 기록할 것
- [p29] [GO/HOLD/DROP]
- evidence 라인 수
- 최소 기준
- 보완 요청 여부
- 검수자/시각

## 9. 플랫폼에서 확인할 것
- UI는 근거 라인 수와 최소 기준을 같이 보여줘야 한다.
- 기준 미달인데 완료 카드가 뜨면 안 된다.
- 근거가 비면 보류 카드로 내려야 한다.
