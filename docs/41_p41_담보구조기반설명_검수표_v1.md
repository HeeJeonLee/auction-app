# p41 담보구조 기반 설명 검수표 v1

대상 사건: 2024타경1001
제안유형: 취하 유도 회수안

## 1. 이 페이지에서 막는 것
- 순위 설명 없이 금액만 나열하는 제안서
- 배당 범위를 빼고 취하안만 말하는 문구
- 담보구조가 불명확한데 결론부터 쓰는 문구

## 2. 설명 템플릿
- 담보순위 확인 -> 예상배당 범위 -> 취하안 회수 비교 순서로 설명한다.
- 순위가 불명확하면 결론 문장을 쓰지 않는다.

## 3. 필수 근거
- 등기부 권리순위 캡처
- 채권최고액/실채권액 구분
- 배당요구 종기 관련 메모

## 4. 통과 예시
- 1순위 근저당과 2순위 권리의 배당 범위를 구분해 설명함
- 채권최고액과 실채권액을 나눠 적음
- 취하안 회수 비교가 등기부 순위와 연결됨

## 5. 판정 순서
1. 권리순위 캡처가 있는지 본다.
2. 채권최고액과 실채권액이 구분되는지 본다.
3. 배당요구 종기 메모가 있는지 본다.
4. 셋 중 하나라도 비면 GO를 주지 않는다.

## 6. 보류 기준
- 순위 캡처는 있는데 금액 구분이 없으면 HOLD.
- 배당요구 종기 메모가 없으면 HOLD.
- 취하안 회수 비교만 있고 담보구조 설명이 없으면 HOLD.

## 7. 반려 조건
- 순위 근거 누락.
- 담보구조 설명 없이 금액만 제시.
- 배당 범위를 쓰지 않고 결론부터 쓰면 DROP.

## 8. 검수 메모 예시
- [p41][HOLD] 권리순위는 있으나 실채권액 구분 누락.
- [p41][DROP] 담보구조 설명 없이 회수액만 적음.

## 9. UI 확인
- 권리순위, 금액 구분, 배당 메모가 같은 화면에 보여야 한다.
- 순위가 없으면 결론 카드가 아니라 보류 카드여야 한다.
- 배당 범위가 빠지면 취하안 비교 버튼을 막아야 한다.
