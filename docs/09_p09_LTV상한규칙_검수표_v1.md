# p09 LTV 상한 규칙 검수표 v1

대상 사건: 2024타경1001
법원: 서울중앙지방법원
주소: 서울시 예시구 예시동
아파트: 예시아파트
부채총액: 600,000,000원
KB시세: 1,200,000,000원
LTV: 0.50
임계치: 0.85

## 1. 이 페이지에서 보는 것
- LTV 수치가 계산되는지 확인한다.
- 임계치 0.85와 비교해서 보수 분기할지 본다.
- 부채총액과 KB시세가 같은 사건 키로 묶이는지 확인한다.

## 2. 입력 필드
- 부채총액
- KB시세
- 감정가
- LTV
- 임계치

## 3. 판정 순서
1. 부채총액과 시세값을 먼저 확인한다.
2. LTV를 계산한다.
3. 0.85 임계치와 비교한다.
4. 수치와 판정이 서로 맞는지 확인한다.

## 4. 통과 기준
- LTV가 숫자로 계산된다.
- 임계치와 판정이 일치한다.
- 원문 캡처와 OCR 추출값이 같은 값을 가리킨다.

## 5. 보류 기준
- LTV 계산이 불가하면 HOLD.
- 부채총액이나 시세값이 하나라도 없으면 HOLD.
- 숫자 단위가 섞이면 HOLD.

## 6. 반려 기준
- LTV 계산 불가인데 GO면 DROP.
- 임계치 초과인데 일반 통과로 남기면 DROP.
- 다른 사건의 시세나 부채를 섞었으면 DROP.

## 7. 샘플 판정 예시
- GO: LTV 0.50 / 임계치 0.85 / 정상 통과
- HOLD: 시세값은 있으나 LTV가 계산되지 않은 경우
- DROP: LTV 0.90인데 일반 통과로 남긴 경우

## 8. 기록할 것
- [p09] [GO/HOLD/DROP]
- LTV 수치
- 임계치 비교 결과
- 원문/OCR 대조 결과
- 검수자/시각

## 9. 플랫폼에서 확인할 것
- UI는 LTV와 임계치를 한 줄에서 같이 보여줘야 한다.
- 임계치 초과이면 자동 승인하지 말고 보수 큐로 보내야 한다.
- 계산 불가 상태를 승인 카드로 보여주면 안 된다.
