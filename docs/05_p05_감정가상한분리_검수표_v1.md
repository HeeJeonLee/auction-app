# p05 감정가 상한 분리 검수표 v1

대상 사건: 2024타경1001
감정가: 1,000,000,000원
상한 기준: 5,000,000,000원

## 1. 이 페이지에서 보는 것
- 감정가가 50억을 넘는지 확인한다.
- 초과 건을 일반 큐와 섞지 않고 별도 트랙으로 보낸다.
- 큰 사건은 같은 화면에서라도 운영 방식이 달라야 한다.

## 2. 입력 필드
- 감정가 원문
- OCR 감정가
- 금액 단위
- 대형딜 트랙 표시
- 일반 큐 표시

## 3. 판정 순서
1. 감정가 숫자를 읽는다.
2. 단위를 확인한다.
3. 50억 초과 여부를 확인한다.
4. 일반 큐에 들어가 있지 않은지 본다.

## 4. 통과 기준
- 감정가가 50억 이하다.
- 초과 건은 대형딜 트랙으로 분리된다.
- 일반 큐와 대형딜 큐가 섞이지 않는다.

## 5. 보류 기준
- 감정가가 50억 근처인데 단위가 불명확하면 HOLD.
- 초과 여부를 OCR만으로 확정하기 어려우면 HOLD.
- 대형딜 트랙 표시가 없으면 HOLD.

## 6. 반려 기준
- 감정가가 50억 초과인데 일반 큐에 남아 있으면 DROP.
- 대형딜 분리가 안 되면 DROP.
- 금액 단위를 끝내 정정하지 못하면 DROP.

## 7. 샘플 판정 예시
- GO: 1,000,000,000원처럼 50억 이하인 경우
- HOLD: 49억대인데 OCR이 흔들려 숫자가 잘리는 경우
- DROP: 5,100,000,000원처럼 상한 초과가 확정된 경우

## 8. 기록할 것
- [p05] [GO/HOLD/DROP]
- 감정가 원문
- OCR 감정가
- 대형딜 분리 여부
- 보완 요청 필드
- 검수자/시각

## 9. 플랫폼에서 확인할 것
- UI는 p05 카드에 감정가와 큐 분리 결과를 함께 보여줘야 한다.
- 초과건은 일반 큐보다 위가 아니라 별도 영역으로 분리해야 한다.
- 초과인데 일반 카드로 보여주면 안 된다.
