# p46 결렬 분기 규칙 검수표 v1

대상 사건: 2024타경1001
제안유형: 취하 유도 회수안

## 1. 이 페이지에서 막는 것
- 결렬 사유를 코드 없이 주관적으로 기록하는 방식
- 같은 결렬 패턴을 반복하면서도 담당자와 액션이 안 바뀌는 상태
- DROP 사유가 없는데 케이스를 종료하는 방식

## 2. 결렬 코드
- C1: 조건 불일치
- C2: 증빙 부족
- C3: 의사결정 지연
- C4: 정책 불가

## 3. 코드별 액션
- C1: 금액/기한 재설계 후 1회 재접촉
- C2: 증빙 확보 전까지 접촉 중단
- C3: 상위결재 라인 재지정
- C4: 즉시 DROP 및 사유 보관

## 4. 재접촉 제한
- 동일 코드 2회 반복 시 담당자 교체

## 5. 통과 예시
- C1로 분류 후 금액/기한 재설계, 1회 재접촉 진행
- C2로 분류 후 증빙 확보 전까지 접촉 중단 기록
- C4는 DROP과 사유 보관까지 완료

## 6. 판정 순서
1. 결렬 코드를 먼저 고른다.
2. 코드별 액션이 실행됐는지 본다.
3. 재접촉 횟수와 담당자 변경 여부를 본다.
4. 코드 없이 종료되면 GO를 주지 않는다.

## 7. 보류 기준
- 결렬 코드는 있는데 액션 로그가 없으면 HOLD.
- 동일 코드 반복인데 담당자 변경이 없으면 HOLD.
- DROP인데 사유 보관이 없으면 HOLD.

## 8. 반려 조건
- 결렬 코드 미기록.
- 코드와 다른 액션 수행.
- 반복 결렬인데도 재접촉 제한 무시.

## 9. 검수 메모 예시
- [p46][HOLD] C2 분류는 했지만 증빙 확보 전 접촉 중단 로그 누락.
- [p46][DROP] 결렬 코드 없이 임의 종료 처리.

## 10. UI 확인
- 코드 선택, 코드별 액션, 재접촉 제한이 한 화면에 보여야 한다.
- 같은 코드 2회 반복이면 담당자 변경 알림이 떠야 한다.
- DROP은 사유 보관 필드 없이는 완료 처리되면 안 된다.
