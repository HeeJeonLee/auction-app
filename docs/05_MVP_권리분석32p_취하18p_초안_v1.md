# MVP 매뉴얼 50P 초안 v1

범위: 서울/수도권 아파트, 감정가 5억~50억(초과건 별도 트랙)
목표: OCR 결과를 규칙 엔진에 바로 연결해 점수/판정/취하 스크립트를 자동 생성
버전: MVP-2026.08-v1

---

## p01. 사건 식별 필수키 정의
- 목적: 사건번호/법원명/주소 3키를 필수 식별키로 고정
- 규칙ID: RA-01, RA-02, RA-03
- 입력: 공고문, OCR 텍스트, 사용자 보완 입력
- 절차:
1. 사건번호 정규화(YYYY타경NNNN)
2. 법원명 표준화(지방법원/지원)
3. 주소에서 시군구+동호 분리
- 산출: 사건식별키 검증표
- 예외: 사건번호 미확인 시 즉시 HOLD
- 출처: 법원경매정보 사건 기본정보 항목

## p02. 사건번호 정규화 규칙
- 목적: 동일 사건의 중복/분산 저장 방지
- 규칙ID: RA-01
- 핵심조건: 사건번호 exists
- 절차:
1. 공백/특수문자 제거
2. 타경 패턴 미일치 시 원문보관+경고
3. 관련사건번호는 보조키로 저장
- 산출: 정규화 사건번호 + 원문 사건번호
- 반례: OCR이 '타경'을 '타걍'으로 오인식한 경우 수동보정

## p03. 법원/주소 정합성 검증
- 목적: 법원명과 주소 지역의 상충 탐지
- 규칙ID: RA-02, RA-03, RA-06
- 절차:
1. 법원명 추출
2. 주소 추출
3. 서울/경기/인천 토큰 여부 확인
- 산출: 지역적합 판정
- 예외: 주소 누락 시 DROP 금지, HOLD 후 보완요청
- 출처: 플랫폼 대상 범위 정책

## p04. 감정가 하한 필터
- 목적: 감정가 5억 미만 사건 사전 제외
- 규칙ID: RA-04
- 조건식: 감정가 >= 500,000,000
- 절차:
1. 감정가 숫자 정규화
2. 하한 미달 시 제외 큐 이동
- 산출: 대상/비대상 라벨
- 반례: 감정가 단위 오인식(만원/원 혼동)

## p05. 감정가 상한 트랙 분리
- 목적: 50억 초과 대형딜을 별도 트랙으로 분리
- 규칙ID: RA-05
- 조건식: 감정가 <= 5,000,000,000
- 절차:
1. 상한 초과 시 플래그 부여
2. 일반 트랙 분석 결과와 분리 저장
- 산출: 일반트랙/대형트랙 구분
- 출처: 운영 효율성 기준

## p06. 수도권 범위 제한
- 목적: 서울/수도권 범위 외 사건의 자동 분류
- 규칙ID: RA-06
- 절차:
1. 법원명/주소 결합 텍스트 생성
2. 서울/경기/인천 토큰 매칭
3. 미매칭 시 HOLD
- 산출: 지역적합 여부, 보완요청 문구
- 반례: 주소 OCR 누락으로 지역 미매칭

## p07. 부채총액 필수화
- 목적: 부채총액 미확정 상태의 허술한 결론 차단
- 규칙ID: RA-07
- 절차:
1. 청구금액/채권최고액 추출
2. 권리항목 금액 합산과 비교
3. 대표값 1개 확정
- 산출: 부채총액, 출처태그
- 출처: 민사집행 실무의 배당 비교 필요조건

## p08. 시세 필수화
- 목적: KB시세 또는 대체시세 확보
- 규칙ID: RA-08
- 절차:
1. KB시세 우선
2. 미존재 시 대체시세+출처 기록
3. 기준일 6개월 초과시 경고
- 산출: 시세값, 시세출처, 기준일
- 반례: 캡처 잘림으로 시세 숫자 일부 누락

## p09. LTV 상한 규칙
- 목적: 고LTV 고위험 사건을 취하 접근 전 분리
- 규칙ID: RA-09
- 조건식: 부채총액 / KB시세 <= 0.85
- 절차:
1. LTV 계산
2. 85% 초과면 HOLD
3. 보완전략(추가상환, 조건조정) 문구 생성
- 산출: LTV, 위험라벨
- 출처: 내부 정책 임계치

## p10. 권리리스크 개수 상한
- 목적: 권리플래그 다중 발생 사건의 자동 경고
- 규칙ID: RA-10
- 조건식: 권리 리스크 플래그 <= 3
- 절차:
1. 근저당/압류/가압류/가처분/임차권/전세권/가등기 집계
2. 3개 초과 시 정밀검토 큐 등록
3. 취하 스크립트에 리스크 문구 자동 삽입
- 산출: 리스크 개수, 검토 큐 여부
- 출처: 권리분석 정밀검토 기준

## 규칙 데이터화 매핑 표 (p01~p10)
- RA-01: 사건번호 exists, weight 10, risk critical_missing_case_no
- RA-02: 법원명 exists, weight 7, risk missing_court
- RA-03: 주소 exists, weight 10, risk critical_missing_address
- RA-04: 감정가 >= 5억, weight 10, risk below_min_appraisal
- RA-05: 감정가 <= 50억, weight 6, risk above_preferred_band
- RA-06: 지역 in 서울/경기/인천, weight 9, risk out_of_region_scope
- RA-07: 부채총액 numeric exists, weight 8, risk missing_debt
- RA-08: KB시세 numeric exists, weight 7, risk missing_kb_price
- RA-09: LTV <= 0.85, weight 12, risk high_ltv
- RA-10: 권리플래그 <= 3, weight 9, risk excessive_rights_risk
