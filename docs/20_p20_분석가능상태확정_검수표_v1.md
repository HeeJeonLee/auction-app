# p20 분석 가능 상태 확정 검수표 v1

대상 사건: 2024타경1001
법원: 서울중앙지방법원
주소: 서울시 예시구 예시동
아파트: 예시아파트
핵심 필드 채움률: 92%
결론 생성 가능: YES

## 1. 이 페이지에서 보는 것
- 지금 사건을 바로 분석해도 되는지 확인한다.
- 필수 필드가 비어 있는데 결론이 먼저 나가면 막는다.
- 채움률만 높고 실제 핵심값이 빠진 상태인지 확인한다.

## 2. 입력 필드
- 핵심 필드 채움률
- 사건번호
- 법원명
- 주소
- 아파트명

## 3. 판정 순서
1. 핵심 필드가 얼마나 채워졌는지 본다.
2. 결론 생성 가능 여부를 확인한다.
3. 누락 필드가 핵심인지 아닌지 구분한다.
4. 원문과 OCR이 같은 사건 키로 묶였는지 본다.

## 4. 통과 기준
- 채움률이 기준 이상이다.
- 분석 시작 전에 빠진 핵심값이 없다.
- 결론 생성 가능 라벨과 수치가 맞는다.

## 5. 보류 기준
- 채움률은 높지만 감정가나 부채총액이 빠지면 HOLD.
- 수치가 있는데 핵심 필드가 하나라도 비면 HOLD.
- 결론 가능 라벨이 애매하면 HOLD.

## 6. 반려 기준
- 채움률 미달인데 결론을 내면 DROP.
- 결론 생성 불가인데 일반 통과로 넘기면 DROP.
- 다른 사건의 채움률을 가져오면 DROP.

## 7. 샘플 판정 예시
- GO: 핵심 필드 채움률 92% / 결론 생성 가능 YES
- HOLD: 채움률은 높지만 감정가가 아직 비어 있는 경우
- DROP: 채움률 68%인데 분석 결과를 먼저 만든 경우

## 8. 기록할 것
- [p20] [GO/HOLD/DROP]
- 핵심 필드 채움률
- 결론 생성 가능 여부
- 누락 필드 목록
- 검수자/시각

## 9. 플랫폼에서 확인할 것
- UI는 채움률과 누락 필드를 같이 보여줘야 한다.
- 기준 미달이면 결론 카드가 아니라 보류 카드로 보여야 한다.
- 핵심값 누락 상태를 승인 카드로 보여주면 안 된다.
