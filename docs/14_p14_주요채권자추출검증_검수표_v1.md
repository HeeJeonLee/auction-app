# p14 주요채권자 추출 검증 검수표 v1

대상 사건: 2024타경1001
법원: 서울중앙지방법원
주소: 서울시 예시구 예시동
아파트: 예시아파트
주요채권자: 서울은행
유형: 근저당권자

## 1. 이 페이지에서 보는 것
- 주요채권자 이름이 제대로 추출되는지 확인한다.
- 채권자 유형이 같이 붙는지 본다.
- 채권자 미상 상태에서 스크립트가 나오지 않는지 본다.

## 2. 입력 필드
- 주요채권자 원문
- 채권자명
- 유형
- 사건번호
- 법원명

## 3. 판정 순서
1. 원문에서 채권자명을 찾는다.
2. 표준 명칭으로 맞춘다.
3. 유형을 태깅한다.
4. 이름과 유형이 같은 사건 키인지 확인한다.

## 4. 통과 기준
- 채권자명이 확정된다.
- 채권자 유형이 함께 확정된다.
- 원문과 추출값이 같은 사건으로 묶인다.

## 5. 보류 기준
- 이름은 보이지만 유형이 없으면 HOLD.
- 유형은 보이지만 이름이 애매하면 HOLD.
- OCR이 채권자명을 잘못 읽으면 HOLD.

## 6. 반려 기준
- 채권자 미상인데 스크립트를 생성하면 DROP.
- 다른 사건 채권자명을 붙이면 DROP.
- 이름과 유형이 끝내 같이 확정되지 않으면 DROP.

## 7. 샘플 판정 예시
- GO: 서울은행 / 근저당권자
- HOLD: 이름은 있으나 유형 태그가 비어 있는 경우
- DROP: 채권자명이 공란인데 결과만 생성한 경우

## 8. 기록할 것
- [p14] [GO/HOLD/DROP]
- 채권자명
- 유형
- 원문/OCR 대조 결과
- 검수자/시각

## 9. 플랫폼에서 확인할 것
- UI는 채권자명과 유형을 같이 보여줘야 한다.
- 채권자 미상 상태를 승인 카드로 보여주면 안 된다.
- 유형 태그가 없으면 보류로 내려야 한다.
