# p40 협상 우선순위 큐 검수표 v1

대상 사건: 2024타경1001
제안유형: 취하 유도 회수안

## 1. 이 페이지에서 막는 것
- 순서 없이 먼저 보이는 사건부터 처리하는 방식
- HOLD가 반복되는데 담당자가 그대로인 상태
- DROP 건이 아무 승인 없이 다시 들어오는 상태

## 2. 우선순위 점수
- 우선순위 = (100-규칙점수) * 0.6 + 기한압박점수 * 0.4
- D-7 이내: 100
- D-14 이내: 70
- 그 외: 40

## 3. 운영 룰
- 일일 상위 10건을 오전 큐로 고정한다.
- HOLD 3회 누적 건은 담당자를 바꾼다.
- DROP 건 재진입은 팀장 승인이 있어야 한다.

## 4. 통과 예시
- 규칙점수 62, D-7 이내, 오전 큐 상위 10건 포함.
- HOLD 3회 누적이라 담당자 변경 후 재검수 대기.
- DROP 건은 팀장 승인 없이는 큐 복귀 금지.

## 5. 판정 순서
1. 규칙점수와 기한압박점수를 같이 계산한다.
2. 오전 큐 10건 안에 들어가는지 본다.
3. HOLD 누적 횟수를 본다.
4. DROP 재진입 승인 여부를 본다.

## 6. 보류 기준
- 점수는 있는데 사유코드가 없으면 HOLD.
- HOLD 누적이 3회인데 담당자 변경이 없으면 HOLD.
- DROP 재진입인데 승인자가 없으면 HOLD.

## 7. 반려 기준
- 큐 변경 사유코드 없이 순서만 바꾸면 DROP.
- 상위 10건 규칙을 무시하면 DROP.
- HOLD 반복인데 사람만 안 바꾸면 DROP.

## 8. 기록할 것
- 우선순위 점수
- 기한압박점수
- 사유코드(기한/증빙/채권자 요청/내부판단)
- 담당자 변경 여부

## 9. UI 확인
- 큐 순서와 점수가 같은 화면에 보여야 한다.
- 사유코드가 없으면 순위 옆에 보류가 보여야 한다.
- DROP 재진입은 승인 배지가 붙어야 한다.
