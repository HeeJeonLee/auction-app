# p45 유동화/NPL 대응 문구 검수표 v1

대상 사건: 2024타경1001
제안유형: 취하 유도 회수안

## 1. 이 페이지에서 막는 것
- 건별 수익만 강조하는 문구
- 현금화 시점 분포 없이 단정하는 문구
- NPL 특성상 불확실성을 숨기는 문구

## 2. 구성 원칙
- 건별 수익이 아니라 포트폴리오 회전율 관점으로 설명한다.
- 이행확률과 현금화 시점 분포를 함께 제시한다.

## 3. 필수 지표
- 예상 회수시점 중앙값
- 제안안 이행확률
- 집행비용 절감 추정

## 4. 통과 예시
- 포트폴리오 회전율을 고려하면 현금화 시점 중앙값이 1.8개월 앞당겨짐.
- 제안안 이행확률 72%, 집행비용 300만 원 절감 추정.
- 불확실성은 존재하므로 확정이 아니라 조건부 검토로 제시.

## 5. 판정 순서
1. 회전율 관점이 있는지 본다.
2. 이행확률이 있는지 본다.
3. 현금화 시점 분포가 있는지 본다.
4. 셋 중 하나라도 비면 GO를 주지 않는다.

## 6. 보류 기준
- 회전율은 있는데 이행확률이 없으면 HOLD.
- 현금화 시점 분포가 없으면 HOLD.
- 집행비용 절감 추정이 없으면 HOLD.

## 7. 반려 조건
- 근거 없는 고수익 약속.
- 불확실성 고지 누락.
- 포트폴리오 관점 없이 단건 장점만 나열.

## 8. 검수 메모 예시
- [p45][HOLD] 회전율 설명은 있으나 이행확률 누락.
- [p45][DROP] 고수익 약속만 있고 불확실성 고지가 없음.

## 9. UI 확인
- 회전율, 이행확률, 현금화 시점 분포가 같이 보여야 한다.
- 불확실성 고지가 별도 문장으로 보여야 한다.
- 고수익 표현이 보이면 발송을 보류해야 한다.

- 불확실성 누락은 캡처 인식보다 문구 통제로 먼저 분리한다.
