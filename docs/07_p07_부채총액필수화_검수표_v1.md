# p07 부채총액 필수화 검수표 v1

대상 사건: 2024타경1001
법원: 서울중앙지방법원
주소: 서울시 예시구 예시동
아파트: 예시아파트
청구금액: 650,000,000원
채권최고액: 700,000,000원
부채총액: 600,000,000원

## 1. 이 페이지에서 보는 것
- 부채총액이 비어 있지 않고 숫자로 확정되는지 확인한다.
- 청구금액과 채권최고액 중 무엇을 대표 부채값으로 쓸지 정한다.
- OCR 숫자와 원문 캡처가 같은 사건 키로 묶이는지 확인한다.

## 2. 입력 필드
- 청구금액
- 채권최고액
- 부채총액
- 출처 태그
- 사건번호

## 3. 판정 순서
1. 원문 캡처에서 부채 관련 숫자를 먼저 찾는다.
2. OCR 추출값과 원문 숫자가 같은지 대조한다.
3. 청구금액, 채권최고액, 부채총액 중 대표값을 확정한다.
4. 출처 태그와 사건 키를 함께 남긴다.

## 4. 통과 기준
- 부채총액이 0이 아니고 공란이 아니다.
- 부채총액의 출처가 남아 있다.
- 대표 부채값이 청구금액 또는 채권최고액과 모순되지 않는다.

## 5. 보류 기준
- 부채총액은 보이지만 값이 애매하면 HOLD.
- OCR 숫자와 원문 숫자가 서로 다르면 HOLD.
- 출처 태그가 없으면 HOLD.

## 6. 반려 기준
- 부채총액이 0이면 DROP.
- 부채총액이 공란이면 DROP.
- 사건 키가 맞지 않아 다른 사건의 숫자를 끌어왔으면 DROP.

## 7. 샘플 판정 예시
- GO: 청구금액 6.5억 / 채권최고액 7억 / 부채총액 6억
- HOLD: 부채 숫자는 있으나 OCR과 원문이 서로 다르게 읽힌 경우
- DROP: 부채총액이 공란이거나 0으로만 남은 경우

## 8. 기록할 것
- [p07] [GO/HOLD/DROP]
- 대표 부채값
- 출처 태그
- OCR 대조 결과
- 검수자/시각

## 9. 플랫폼에서 확인할 것
- UI는 청구금액, 채권최고액, 부채총액을 한 줄에서 같이 보여줘야 한다.
- 부채총액이 없으면 자동 승인하지 말고 보류로 내려야 한다.
- 출처 태그가 없으면 승인 카드로 보여주면 안 된다.

## 10. 다음 작업 기준
