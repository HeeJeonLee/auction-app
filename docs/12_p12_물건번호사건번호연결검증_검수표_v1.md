# p12 물건번호/사건번호 연결 검증 검수표 v1

대상 사건: 2024타경1001
법원: 서울중앙지방법원
주소: 서울시 예시구 예시동
사건번호: 2024타경1001
물건번호: 1

## 1. 이 페이지에서 보는 것
- 사건번호와 물건번호가 같은 사건으로 묶이는지 확인한다.
- 중복 병합이 일어나지 않는지 본다.
- 주소까지 함께 봐서 다른 사건과 섞이지 않는지 확인한다.

## 2. 입력 필드
- 사건번호
- 물건번호
- 주소
- 법원명
- 사건 키

## 3. 판정 순서
1. 사건번호를 먼저 확정한다.
2. 물건번호가 있는지 확인한다.
3. 사건번호와 물건번호로 조합키를 만든다.
4. 조합키가 중복인지 확인한다.

## 4. 통과 기준
- 사건번호와 물건번호가 둘 다 있다.
- 조합키가 고유하다.
- 주소와 법원명도 같은 사건으로 읽힌다.

## 5. 보류 기준
- 물건번호는 있으나 사건번호가 잘리면 HOLD.
- 조합키가 맞는지 아직 확정 못 하면 HOLD.
- 주소가 애매해 다른 사건 가능성이 있으면 HOLD.

## 6. 반려 기준
- 물건번호 누락을 다른 사건과 병합하면 DROP.
- 사건번호와 물건번호 조합이 다르면 DROP.
- 다른 사건 키를 가져와 중복 저장하면 DROP.

## 7. 샘플 판정 예시
- GO: 2024타경1001 / 물건 1 / 주소 일치
- HOLD: 사건번호는 보이지만 물건번호가 잘린 경우
- DROP: 물건번호 누락 사건을 기존 사건과 병합한 경우

## 8. 기록할 것
- [p12] [GO/HOLD/DROP]
- 사건번호
- 물건번호
- 조합키
- 중복 여부
- 검수자/시각

## 9. 플랫폼에서 확인할 것
- UI는 사건번호와 물건번호를 같은 카드에서 보여줘야 한다.
- 조합키가 중복이면 자동 병합하면 안 된다.
- 주소가 불일치하면 승인 카드로 보여주면 안 된다.
