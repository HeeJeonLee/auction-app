# p18 등기부 열람필수 분기 검수표 v1

대상 사건: 2024타경1001
법원: 서울중앙지방법원
주소: 서울시 예시구 예시동
아파트: 예시아파트
권리요약: 근저당 1, 압류 1, 전세권 없음
권리플래그: 근저당/압류
열람필수 태그: YES

## 1. 이 페이지에서 보는 것
- 중대 권리가 보이면 등기부를 꼭 열어야 하는지 확인한다.
- 열람필수 태그가 자동으로 붙는지 본다.
- 위험한데도 그냥 지나가는 카드가 없는지 확인한다.

## 2. 입력 필드
- 권리요약
- 권리플래그
- 열람필수 태그
- 사건번호
- 법원명

## 3. 판정 순서
1. 권리요약에서 중대 권리를 찾는다.
2. 권리플래그와 함께 읽는다.
3. 열람필수 태그가 붙어야 하는지 판단한다.
4. 태그가 원문과 OCR 둘 다에서 같은지 확인한다.

## 4. 통과 기준
- 중대 권리가 있으면 열람필수 태그가 붙는다.
- 위험 사유와 태그가 서로 맞는다.
- 원문과 OCR이 같은 사건을 가리킨다.

## 5. 보류 기준
- 권리요약은 있는데 열람필수 태그가 비면 HOLD.
- 위험은 보이는데 태그가 애매하면 HOLD.
- OCR이 권리플래그를 일부 잘라 먹으면 HOLD.

## 6. 반려 기준
- 중대권리인데 열람필수 누락이면 DROP.
- 위험한데도 일반 통과로 남기면 DROP.
- 다른 사건 권리요약을 가져오면 DROP.

## 7. 샘플 판정 예시
- GO: 근저당 1, 압류 1 -> 열람필수 YES
- HOLD: 권리요약은 있으나 태그가 아직 비어 있는 경우
- DROP: 중대권리가 보이는데도 일반 통과로 남긴 경우

## 8. 기록할 것
- [p18] [GO/HOLD/DROP]
- 권리요약
- 열람필수 태그
- 위험 사유
- 검수자/시각

## 9. 플랫폼에서 확인할 것
- UI는 위험 사유와 열람필수 태그를 같이 보여줘야 한다.
- 태그가 없으면 승인 카드가 아니라 보류 카드로 보여야 한다.
- 중대권리인데도 일반 통과 카드가 뜨면 안 된다.

## 10. 다음 작업 기준
