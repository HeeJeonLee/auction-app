# p37 반론 대응 준비도 검수표 v1

대상 사건: 2024타경1001
채권자: OO저축은행
제안유형: 취하 유도 회수안

## 1. 이 페이지에서 막는 것
- 답변이 비어 있는 상태로 채권자에게 먼저 던지는 제안서
- 숫자만 있고 반론 대응이 없는 제안서
- 내부 승인질문에 대한 설명이 없는 제안서

## 2. 필수 반론 5종
- 왜 지금 취하해야 하는가?
- 경매를 계속하면 손실이 얼마나 나는가?
- 제안이 깨지면 다음 수순은 무엇인가?
- 내부 승인과 법적 리스크는 어떻게 처리하는가?
- 누가 언제까지 책임지고 실행하는가?

## 3. 준비도 점검
- 반론별 답변문이 1개씩 있어야 한다.
- 숫자 근거는 최소 2개가 있어야 한다.
- 증빙 파일 링크는 최소 1개가 있어야 한다.

## 4. 통과 예시
- 경매 지속 대비 회수시점이 3.2개월 늦어짐
- 순회수액 차이가 5,000만 원 이상임
- 납입확약서와 실행캘린더가 함께 준비됨

## 5. 판정 순서
1. 반론 5종에 대한 답이 있는지 본다.
2. 숫자 근거가 근거로 읽히는지 본다.
3. 증빙이 실제 파일로 붙어 있는지 본다.
4. 셋 중 하나라도 비면 GO를 주지 않는다.

## 6. 보류 기준
- 5종 중 2~3종만 준비되면 HOLD.
- 답변은 있는데 숫자 근거가 없으면 HOLD.
- 증빙 링크가 깨졌거나 비어 있으면 HOLD.

## 7. 반려 기준
- 1종 이하만 준비되면 DROP.
- 내부승인 질문을 피하는 답변만 있으면 DROP.
- 책임자와 시간표가 없으면 DROP.

## 8. 검수 메모 예시
- [p37][HOLD] 손실 근거는 있으나 내부 승인 리스크 답변 누락.
- [p37][DROP] 반론 5종 중 2종만 준비. 채권자 발송 보류.

## 9. UI 확인
- 반론 5종과 답변 상태가 같은 화면에 보여야 한다.
- 답변 미작성 항목은 빈칸이 아니라 빨간 보류 표시가 나와야 한다.
- 증빙 링크가 없으면 발송 버튼이 활성화되면 안 된다.
