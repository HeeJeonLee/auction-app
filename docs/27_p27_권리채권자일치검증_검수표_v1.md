# p27 권리-채권자 일치 검증 검수표 v1

대상 사건: 2024타경1001
법원: 서울중앙지방법원
주소: 서울시 예시구 예시동
아파트: 예시아파트
권리요약: 근저당 1, 압류 1
주요채권자: 서울은행
채권자 유형: 근저당권자

## 1. 이 페이지에서 보는 것
- 권리 내용과 채권자 성격이 서로 맞는지 확인한다.
- 근저당인데 압류권자처럼 적히는 실수를 막는다.
- 권리요약만 있고 채권자 성격이 엇나가면 바로 잡는다.

## 2. 입력 필드
- 권리요약
- 주요채권자
- 채권자 유형
- 사건번호
- 법원명

## 3. 판정 순서
1. 권리요약을 먼저 읽는다.
2. 주요채권자의 성격을 확인한다.
3. 두 값이 같은 사건 설명인지 교차검증한다.
4. 불일치가 있으면 왜 틀렸는지 적는다.

## 4. 통과 기준
- 권리와 채권자 유형이 서로 맞는다.
- 채권자 성격이 권리 내용과 어긋나지 않는다.
- 원문과 OCR이 같은 사건 키를 가리킨다.

## 5. 보류 기준
- 권리요약은 있으나 채권자 유형이 비면 HOLD.
- 유형은 있는데 권리 설명이 애매하면 HOLD.
- 채권자명이 맞는지 아직 확정 못 하면 HOLD.

## 6. 반려 기준
- 유형 불일치가 명확하면 DROP.
- 다른 사건 채권자를 붙이면 DROP.
- 권리요약과 채권자 성격이 끝내 안 맞으면 DROP.

## 7. 샘플 판정 예시
- GO: 근저당 1, 압류 1 / 서울은행 / 근저당권자
- HOLD: 권리요약은 있으나 채권자 유형이 비어 있는 경우
- DROP: 근저당인데 압류권자로 잘못 표기한 경우

## 8. 기록할 것
- [p27] [GO/HOLD/DROP]
- 권리요약
- 주요채권자
- 채권자 유형
- 불일치 여부
- 검수자/시각

## 9. 플랫폼에서 확인할 것
- UI는 권리요약과 채권자 유형을 같이 보여줘야 한다.
- 유형이 안 맞으면 승인 카드로 보여주면 안 된다.
- 불일치가 있으면 보류 카드로 내려야 한다.
