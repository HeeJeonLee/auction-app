# p26 LTV 경계구간 경고(80~85) 검수표 v1

대상 사건: 2024타경1001
법원: 서울중앙지방법원
주소: 서울시 예시구 예시동
아파트: 예시아파트
부채총액: 850,000,000원
KB시세: 1,000,000,000원
LTV: 0.85
경계 라벨: HOLD 우선

## 1. 이 페이지에서 보는 것
- LTV가 0.80에서 0.85 사이인지 확인한다.
- 경계값이면 무리하게 GO로 두지 않는지 본다.
- 숫자는 맞는데 판단이 너무 빨리 끝나지 않는지 확인한다.

## 2. 입력 필드
- LTV
- 경계 라벨
- 부채총액
- KB시세
- 사건번호

## 3. 판정 순서
1. LTV를 먼저 본다.
2. 0.80~0.85 사이인지 확인한다.
3. 경계면이면 HOLD 우선으로 둔다.
4. 보완 조건이 필요한지 메모를 확인한다.

## 4. 통과 기준
- 경계 구간이면 HOLD 우선 라벨이 붙는다.
- 보완 조건이 같이 적혀 있다.
- 원문과 OCR이 같은 사건 키로 연결된다.

## 5. 보류 기준
- 경계인데 GO로 바로 밀면 HOLD.
- 라벨은 있는데 보완 조건이 없으면 HOLD.
- 수치는 맞지만 근거가 약하면 HOLD.

## 6. 반려 기준
- 0.80~0.85 구간인데 일반 GO로 남기면 DROP.
- 다른 사건 LTV를 가져오면 DROP.
- 경계 라벨 없이 결론만 내면 DROP.

## 7. 샘플 판정 예시
- GO: 0.78 / 경계 밖이라 일반 통과
- HOLD: 0.85 / 경계 구간 / 보완 조건 필요
- DROP: 0.84인데 아무 설명 없이 GO 처리한 경우

## 8. 기록할 것
- [p26] [GO/HOLD/DROP]
- LTV
- 경계 라벨
- 보완 조건
- 검수자/시각

## 9. 플랫폼에서 확인할 것
- UI는 경계값이면 HOLD 우선으로 보여줘야 한다.
- 경계구간인데 GO 카드가 뜨면 안 된다.
- 보완 조건이 없으면 완료 카드로 보이면 안 된다.
