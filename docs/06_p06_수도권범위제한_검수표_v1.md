# p06 수도권 범위 제한 검수표 v1

대상 사건: 2024타경1001
법원: 서울중앙지방법원
주소: 서울시 예시구 예시동
범위 기준: 서울/경기/인천 아파트만 검수

## 1. 이 페이지에서 보는 것
- 사건이 서울/경기/인천 범위에 들어오는지 확인한다.
- 법원명과 주소가 수도권으로 같이 읽히는지 확인한다.
- 비수도권 사건이 섞이지 않았는지 확인한다.

## 2. 입력 필드
- 법원명
- 주소
- 시군구 토큰
- 아파트명
- 사건번호

## 3. 판정 순서
1. 법원명에서 권역을 먼저 본다.
2. 주소에서 시군구와 광역권을 본다.
3. 서울/경기/인천 토큰이 있는지 본다.
4. 아파트명과 주소가 같은 사건인지 확인한다.

## 4. 통과 기준
- 서울/경기/인천 사건이다.
- 법원명과 주소 권역이 맞는다.
- 아파트 사건으로 읽힌다.

## 5. 보류 기준
- 주소는 있으나 권역이 불명확하면 HOLD.
- 법원명은 수도권인데 주소가 잘렸으면 HOLD.
- OCR이 서울/경기를 잘못 읽었을 가능성이 있으면 HOLD.

## 6. 반려 기준
- 부산/대구/광주 등 비수도권이면 DROP.
- 법원명과 주소 권역이 끝내 맞지 않으면 DROP.
- 수도권 여부를 정정할 근거가 없으면 DROP.

## 7. 샘플 판정 예시
- GO: 서울중앙지방법원 / 서울시 예시구 예시동 / 예시아파트
- HOLD: 법원명은 서울이나 주소가 시군구까지만 읽힌 경우
- DROP: 법원명 또는 주소가 비수도권으로 확정된 경우

## 8. 기록할 것
- [p06] [GO/HOLD/DROP]
- 법원명 판정 결과
- 주소 권역 판정 결과
- 아파트명 일치 여부
- 보완 요청 필드
- 검수자/시각

## 9. 플랫폼에서 확인할 것
- UI는 p06 카드에 법원명과 주소 권역을 함께 보여줘야 한다.
- 수도권이 아니면 적격 카드가 아니라 제외 카드로 보여야 한다.
- 애매하면 자동 승인하면 안 된다.
