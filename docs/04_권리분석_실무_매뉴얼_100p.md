# 권리분석 실무 매뉴얼 100P (실무 본문 완성판)

본 문서는 p01~p100을 제목형 요약이 아니라, 담당자가 바로 실행 가능한 본문형 절차서로 구성했다.
각 페이지에는 목적, 입력자료, 배경설명, 작업 절차, 산출물, 체크리스트, 오류사례, 보고문안, 현장 팁을 포함한다.

---

## p01. 사건 기본정보 수집 범위 정의

목적: 사건 기본정보 수집 범위 정의 업무를 재현 가능한 표준 절차로 고정하여 담당자 변경 시에도 동일한 품질의 판단을 유지한다.
입력자료: 공고문 원문, OCR 텍스트, 캡처 이미지, 수기 보완 입력, 사건 기본 DB
실무 배경: 이 단계는 사건 식별과 원천 데이터 정합성을 확정하는 구간이다. 여기서 필드 누락이나 표기 오류를 남기면 뒤 단계의 계산이 모두 맞아도 결론이 틀릴 수 있으므로, 원문 근거 링크와 누락 플래그를 동시에 관리해야 한다.

작업 절차:
1. 원문 2종 이상을 교차 확인해 기본 식별값을 확정한다.
2. 필수/선택 필드를 분리하고 누락 허용범위를 명시한다.
3. 금액/날짜/사건번호 정규화 규칙을 적용한다.
4. 필드별 근거 링크를 저장한다.
5. 누락 항목은 즉시 보완요청으로 발행한다.
6. 검수자가 5분 내 재현 가능한지 점검한다.

산출물: 사건 기본카드, 누락 보완요청서, 근거 링크 포함 1차 요약문

검증 체크리스트:
- 사건번호/법원명 일치
- 주소/단지명 일치
- 금액 단위 통일
- 시세 기준일 기록
- 누락 보완요청 발행

오류사례: p01 단계에서 자주 발생하는 오류는 원문 근거 없이 결론을 확정하거나 누락값을 추정으로 채운 뒤 표기하지 않는 경우다. 이 경우 다음 단계에서 계산이 맞아도 의사결정 신뢰도가 무너진다.
보고문안 예시: "p01 검토 결과 핵심 근거 3건을 확인했고, 현재 판단은 조건부 유효입니다. 보완 항목 2건(증빙/기한) 완료 시 최종 확정 가능합니다."
현장 팁: 결과 수치만 전달하지 말고, 다음 담당자가 5분 내 재현 가능한 입력 위치와 검증 포인트를 함께 넘긴다.
