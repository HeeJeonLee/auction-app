# p08 시세 필수화 검수표 v1

대상 사건: 2024타경1001
법원: 서울중앙지방법원
주소: 서울시 예시구 예시동
아파트: 예시아파트
KB시세: 1,200,000,000원
기준일: 2026-08-10
출처: KB시세

## 1. 이 페이지에서 보는 것
- 시세값이 숫자로 확정되는지 확인한다.
- 기준일이 같이 붙어 있는지 확인한다.
- KB시세가 없으면 대체시세로 넘어갈 수 있는지 본다.

## 2. 입력 필드
- KB시세
- 대체시세
- 기준일
- 출처 태그
- 사건번호

## 3. 판정 순서
1. KB시세가 있는지 먼저 본다.
2. 없으면 대체시세를 확인한다.
3. 기준일이 붙어 있는지 확인한다.
4. 출처 태그가 원문과 맞는지 확인한다.

## 4. 통과 기준
- 시세값이 0이 아니고 공란이 아니다.
- 기준일이 같이 남아 있다.
- 출처 태그가 있다.

## 5. 보류 기준
- 시세값은 있으나 기준일이 없으면 HOLD.
- KB시세와 대체시세가 충돌하면 HOLD.
- 출처 태그가 없으면 HOLD.

## 6. 반려 기준
- 시세값이 공란이면 DROP.
- 기준일이 끝내 확인되지 않으면 DROP.
- 다른 사건의 시세를 가져왔으면 DROP.

## 7. 샘플 판정 예시
- GO: KB시세 12억 / 기준일 2026-08-10 / 출처 KB시세
- HOLD: 시세값은 있으나 기준일이 비어 있는 경우
- DROP: 시세값이 공란이거나 다른 사건의 값인 경우

## 8. 기록할 것
- [p08] [GO/HOLD/DROP]
- 시세값
- 기준일
- 출처 태그
- OCR 대조 결과
- 검수자/시각

## 9. 플랫폼에서 확인할 것
- UI는 시세, 기준일, 출처를 한 줄에서 같이 보여줘야 한다.
- 기준일이 없으면 자동 승인하지 말고 보류로 내려야 한다.
- 출처가 불명확하면 승인 카드로 보여주면 안 된다.
