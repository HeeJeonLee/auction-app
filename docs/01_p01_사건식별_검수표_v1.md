# p01 사건 식별 검수표 v1

대상 사건: 2024타경1001
법원: 서울중앙지방법원
주소: 서울시 예시구 예시동
아파트: 예시아파트
감정가: 1,000,000,000원
최저매각가격: 800,000,000원
낙찰예상가: 900,000,000원
부채총액: 600,000,000원
KB시세: 1,200,000,000원

## 1. 이 페이지에서 보는 것
- 사건번호, 법원명, 주소, 물건번호가 같은 사건으로 안정적으로 묶이는지 확인한다.
- 금액 필드가 원문과 같은 단위로 읽히는지 확인한다.
- 이 페이지에서 틀리면 다음 페이지로 넘어가지 않는다.

## 2. 입력 필드
- 사건번호
- 법원명
- 주소
- 물건번호
- 아파트명
- 감정가
- 최저매각가격
- 낙찰예상가
- 부채총액
- KB시세

## 3. 원문 확인 순서
1. 캡처 상단의 사건번호를 먼저 확인한다.
2. 법원명과 주소가 같은 화면에 있는지 확인한다.
3. 물건번호와 아파트명이 다른 사건으로 섞이지 않았는지 확인한다.
4. 감정가, 최저매각가격, 낙찰예상가, 부채총액, KB시세를 하나씩 대조한다.

## 4. 통과 기준
- 사건번호가 1개로 확정된다.
- 법원명과 주소가 같은 사건으로 귀속된다.
- 감정가, 최저매각가격, 부채총액, KB시세가 모두 숫자와 단위까지 명확하다.
- 서울/수도권 아파트 범위에 들어온다.

## 5. 보류 기준
- 사건번호가 잘려 보이거나 OCR이 엉키면 HOLD.
- 주소 동/호가 잘려서 같은 사건인지 불명확하면 HOLD.
- 금액 단위가 원/만원으로 헷갈리면 HOLD.
- 법원명과 주소 권역이 불일치하면 HOLD.

## 6. 반려 기준
- 감정가 5억 미만이면 DROP.
- 감정가 50억 초과면 DROP.
- 서울/수도권 아파트가 아니면 DROP.
- 사건번호와 주소를 끝내 못 맞추면 DROP.

## 7. 샘플 판정 예시
- GO: 2024타경1001 / 서울중앙지방법원 / 서울시 예시구 예시동 / 예시아파트
- HOLD: 사건번호는 읽혔지만 주소 동/호가 잘려 다른 사건과 섞일 가능성이 있음
- DROP: 감정가가 50억 초과이거나 비수도권 사건

## 8. 기록할 것
- [p01] [GO/HOLD/DROP]
- 사건번호 확인 결과
- 법원명/주소 정합성 결과
- 금액 단위 확인 결과
- 보완 요청 필드
- 검수자/시각

## 9. 플랫폼에서 확인할 것
- UI는 p01 카드에서 사건번호, 법원명, 주소, 감정가, 최저매각가격, 부채총액, KB시세를 한 번에 보여줘야 한다.
- 원문과 OCR 추출값이 다르면 카드 아래에 둘 다 보여줘야 한다.
- p01이 통과하지 못하면 다음 페이지는 열지 않는다.

## 10. 다음 작업 기준
- p01이 승인되면 p02 사건번호 정규화 규칙으로 넘어간다.
- p01에서 발견된 오인식 유형은 캡쳐 인식 보완 항목으로 넘긴다.
