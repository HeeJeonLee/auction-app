# p36 제안조건 최소 세트 검수표 v1

대상 사건: 2024타경1001
채권자: OO저축은행
채무자: 홍길동
제안유형: 취하 유도 회수안

## 1. 이 페이지에서 막는 것
- 금액만 있고 기한이 없는 제안서
- 기한은 있는데 증빙이 없는 제안서
- 실행일정이 비어 있는데도 발송하려는 제안서

## 2. 최소 세트 3요소
- 금액: 총 제안회수액, 분할이면 회차별 금액까지 적는다.
- 기한: 첫 납입일, 완납일, 지연 시 조치까지 적는다.
- 증빙: 자금출처, 납입확약서, 실행캘린더를 붙인다.

## 3. 통과 예시
- 총 제안회수액 8억 2천만 원
- 1차 2억 원은 7일 이내 납입
- 잔액은 30일 이내 완납
- 자금출처 확인서와 납입확약서 첨부

## 4. 판정 순서
1. 금액이 숫자로 적혔는지 본다.
2. 기한이 날짜로 적혔는지 본다.
3. 증빙 파일이 실제로 붙었는지 본다.
4. 셋 중 하나라도 비면 발송을 멈춘다.

## 5. 보류 기준
- 금액과 기한은 있는데 증빙 링크가 없으면 HOLD.
- 분할안인데 회차별 금액이 없으면 HOLD.
- 완납일은 있는데 첫 납입일이 없으면 HOLD.

## 6. 반려 기준
- 3요소 중 1개라도 누락되면 발송 금지.
- 기한 없는 금액 제안은 즉시 반려.
- 증빙 없는 고액 제안은 HOLD가 아니라 사실상 중지.

## 7. 검수 메모 예시
- [p36][HOLD] 완납기한 누락. 48시간 내 납입확약서 보완 요청.
- [p36][DROP] 금액만 있고 증빙 없음. 발송 버튼 비활성화.

## 8. 운영 체크
- 문서에는 제안금액이 실제 납입계획과 연결돼 있어야 한다.
- 날짜는 상대가 이해할 수 있는 표현으로 써야 한다.
- 첨부파일이 없으면 완료로 표시하지 않는다.

## 9. UI 확인
- 금액/기한/증빙이 한 화면에 같이 보여야 한다.
- 셋 중 하나라도 빠지면 "발송 준비 완료" 상태를 띄우지 않는다.
- 보류 사유가 버튼 옆에 바로 보여야 한다.
