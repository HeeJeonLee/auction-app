# p17 부채/시세 역전 경고 검수표 v1

대상 사건: 2024타경1001
법원: 서울중앙지방법원
주소: 서울시 예시구 예시동
아파트: 예시아파트
부채총액: 1,300,000,000원
KB시세: 1,200,000,000원
비율: 1.08

## 1. 이 페이지에서 보는 것
- 부채총액이 시세를 넘는지 확인한다.
- 역전인데도 낮은 위험으로 잘못 분류되지 않았는지 본다.
- 숫자 하나만 보고 지나가면 안 되는 구간인지 확인한다.

## 2. 입력 필드
- 부채총액
- KB시세
- 비율
- 역전 라벨
- 사건번호

## 3. 판정 순서
1. 부채총액과 KB시세를 먼저 본다.
2. 비율을 계산한다.
3. 1.0 초과인지 확인한다.
4. 역전 라벨과 판정이 일치하는지 확인한다.

## 4. 통과 기준
- 비율이 1.0 초과인지 숫자로 확인된다.
- 역전 라벨과 판정이 같다.
- 원문과 OCR 값이 같은 사건 키에 붙는다.

## 5. 보류 기준
- 숫자는 있으나 비율이 애매하면 HOLD.
- 부채총액이나 시세값 중 하나가 흔들리면 HOLD.
- 역전 여부가 확정되지 않으면 HOLD.

## 6. 반려 기준
- 역전인데 저위험으로 처리하면 DROP.
- 다른 사건 시세를 섞으면 DROP.
- 비율이 1.0 초과인데 일반 통과로 남기면 DROP.

## 7. 샘플 판정 예시
- GO: 부채 13억 / 시세 12억 / 비율 1.08 / 역전 라벨 일치
- HOLD: 숫자는 있으나 시세 기준일이 흔들려 비율 해석이 불안정한 경우
- DROP: 역전인데 저위험으로 표시한 경우

## 8. 기록할 것
- [p17] [GO/HOLD/DROP]
- 부채총액
- KB시세
- 비율
- 역전 라벨
- 검수자/시각

## 9. 플랫폼에서 확인할 것
- UI는 부채와 시세를 같은 카드에 보여줘야 한다.
- 역전인데도 일반 통과 카드가 뜨면 안 된다.
- 기준값이 흔들리면 보류로 내려야 한다.
