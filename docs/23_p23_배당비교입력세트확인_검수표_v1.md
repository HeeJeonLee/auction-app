# p23 배당 비교 입력 세트 확인 검수표 v1

대상 사건: 2024타경1001
법원: 서울중앙지방법원
주소: 서울시 예시구 예시동
아파트: 예시아파트
감정가: 1,000,000,000원
최저매각가격: 800,000,000원
낙찰예상가: 900,000,000원
부채총액: 600,000,000원

## 1. 이 페이지에서 보는 것
- 배당 비교에 필요한 4개 숫자가 한 번에 모였는지 확인한다.
- 하나라도 비어 있으면 비교표를 만들면 안 된다.
- 숫자만 있는지, 실제 사건 값인지 확인한다.

## 2. 입력 필드
- 감정가
- 최저가
- 예상가
- 부채
- 사건번호

## 3. 판정 순서
1. 감정가부터 확인한다.
2. 최저가와 예상가를 이어 본다.
3. 부채총액이 같이 붙어 있는지 본다.
4. 4요소가 모두 같은 사건인지 대조한다.

## 4. 통과 기준
- 4요소가 모두 있다.
- 숫자 단위가 서로 섞이지 않는다.
- 비교표를 바로 만들어도 되는 상태다.

## 5. 보류 기준
- 숫자는 있으나 하나라도 빠지면 HOLD.
- 4요소 중 두 개 이상이 OCR에서 흔들리면 HOLD.
- 사건 키가 아직 안 붙으면 HOLD.

## 6. 반려 기준
- 누락 상태인데 배당표를 출력하면 DROP.
- 다른 사건 숫자를 섞으면 DROP.
- 4요소가 덜 찼는데 결론만 내면 DROP.

## 7. 샘플 판정 예시
- GO: 감정가 10억 / 최저가 8억 / 예상가 9억 / 부채 6억
- HOLD: 4개 중 하나가 비어 있어 비교표가 덜 찬 경우
- DROP: 부채가 빠졌는데 완성본으로 저장한 경우

## 8. 기록할 것
- [p23] [GO/HOLD/DROP]
- 4요소 값
- 누락 여부
- 비교표 생성 가능 여부
- 검수자/시각

## 9. 플랫폼에서 확인할 것
- UI는 4요소를 한 줄에서 같이 보여줘야 한다.
- 하나라도 비면 비교표가 아니라 보류 카드로 보여야 한다.
- 누락 상태를 완료 카드로 보여주면 안 된다.

## 10. 다음 작업 기준
- p23 통과 후 p24 사건 단계 라벨링으로 넘어간다.
- 숫자 누락은 캡쳐 인식 보완 항목으로 넘긴다.
