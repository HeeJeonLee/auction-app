# p50 릴리스 게이트 검수표 v1

대상 사건군: 취하 유도 운영 배치
릴리스 대상: rulepack + script + report

## 1. 이 페이지에서 막는 것
- 필수 필드가 비어 있는데 배포를 강행하는 상태
- High 오류가 남아 있는데도 릴리스를 누르는 상태
- 샘플 검수가 미달인데 운영 반영하는 상태

## 2. 배포 전 체크리스트
- 필수필드 채움률 90% 이상
- 규칙판정 생성률 100%
- 취하스크립트 생성률 95% 이상
- 오류 로그 치명도 High 0건
- 수동검수 샘플 10건 PASS

## 3. 실패 시 조치
- High 오류 1건이라도 있으면 배포 중단
- 생성률 미달 시 원인 필드 역추적 후 재실행
- 샘플 PASS 미달 시 규칙/문구 동시 보정

## 4. 배포 승인 기록
- 승인자
- 승인시간
- 릴리스 노트
- 롤백 기준

## 5. 통과 예시
- 필드 채움률 92%, 규칙판정 100%, 스크립트 97%
- High 오류 0건 확인
- 수동검수 10건 전부 PASS 후 승인 기록 완료

## 6. 판정 순서
1. 체크리스트 5개 수치를 먼저 확인한다.
2. 실패 조치가 필요한 항목이 있는지 본다.
3. 승인 기록 4개 항목이 채워졌는지 본다.
4. 하나라도 비면 GO를 주지 않는다.

## 7. 보류 기준
- 수치는 통과했지만 승인시간 누락 시 HOLD.
- High 오류 0건 증빙 캡처가 없으면 HOLD.
- 샘플 PASS 결과 파일이 없으면 HOLD.

## 8. 반려 조건
- High 오류가 남은 채 배포 시도.
- 생성률 미달인데 원인 추적 없이 재시도.
- 승인자 없이 배포 진행.

## 9. UI 확인
- 체크리스트 5개 수치가 한 화면에 보여야 한다.
- High 오류가 1건이라도 있으면 배포 버튼이 잠겨야 한다.
- 승인 기록 4개가 비어 있으면 최종 승인 상태가 나오면 안 된다.

## 10. 최종 메모
- p50 통과 시 p01~p50 검수 체인이 완료된다.
- 이후 변경은 규칙 버전과 매뉴얼 버전을 함께 올려 관리한다.
