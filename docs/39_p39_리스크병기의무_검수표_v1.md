# p39 리스크 병기 의무 검수표 v1

대상 사건: 2024타경1001
제안유형: 취하 유도 회수안

## 1. 이 페이지에서 막는 것
- 장점만 적고 리스크를 숨기는 제안서
- 완화수단 없이 위험만 적는 제안서
- 권리요약과 키워드가 안 맞는 리스크 문구

## 2. 병기 구조
- 기대효과 2개
- 핵심리스크 2개
- 완화수단 2개
- 셋을 한 묶음으로 같이 보여준다.

## 3. 통과 예시
- [효과] 회수시점이 빨라진다.
- [효과] 분쟁비용이 줄어든다.
- [리스크] 납입 실패 가능성이 있다.
- [리스크] 내부 승인 지연 가능성이 있다.
- [완화] 납입확약서 첨부.
- [완화] 책임자와 기한을 명시.

## 4. 판정 순서
1. 효과가 2개인지 본다.
2. 리스크가 2개인지 본다.
3. 완화수단이 2개인지 본다.
4. 셋이 짝을 이루는지 본다.

## 5. 보류 기준
- 효과는 있는데 리스크가 1개뿐이면 HOLD.
- 리스크는 있는데 완화수단이 1개뿐이면 HOLD.
- 문구는 있는데 권리요약 키워드와 다르면 HOLD.

## 6. 반려 기준
- 리스크 없는 제안서는 자동 반려.
- 완화수단이 없는 리스크는 HOLD가 아니라 사실상 중지.
- 리스크와 완화수단이 서로 충돌하면 DROP.

## 7. 검수 메모 예시
- [p39][HOLD] 효과 2개, 리스크 1개만 기재됨.
- [p39][DROP] 장점만 있고 리스크 병기 누락.

## 8. UI 확인
- 효과/리스크/완화가 같은 카드에서 비교돼야 한다.
- 리스크는 빨간색, 완화는 파란색처럼 구분돼야 한다.
- 한쪽만 비어 있으면 발송 버튼이 비활성화돼야 한다.

## 9. 기록할 것
- 효과 2개
- 리스크 2개
- 완화수단 2개
- 권리요약 연동 키워드
