# p43 1금융 스크립트 기준 검수표 v1

대상 사건: 2024타경1001
제안유형: 취하 유도 회수안

## 1. 이 페이지에서 막는 것
- 감성어가 많은데 규정 준수가 없는 문구
- 압박은 강한데 수치가 없는 문구
- 내부통제 문장 없이 바로 실행을 요구하는 문구

## 2. 핵심 문장 구조
- 규정 준수 문장 1개
- 회수 손실 최소화 수치 1개
- 이행 통제(증빙/기한) 문장 1개

## 3. 통과 예시
- 내부 기준과 절차를 준수하는 범위에서 제안합니다.
- 경매 지속 대비 회수 손실을 4,200만 원 줄일 수 있습니다.
- 증빙은 3영업일 내 제출하고, 기한 미준수 시 재검토합니다.

## 4. 품질 게이트
- 감성/압박 문구 비중 30% 초과 시 반려.
- 수치 근거 없는 주장 2개 이상이면 HOLD.
- 규정 준수 문장 없이 제안하면 DROP.

## 5. 판정 순서
1. 규정 준수 문장이 있는지 본다.
2. 회수 손실 수치가 있는지 본다.
3. 증빙/기한 통제 문장이 있는지 본다.
4. 셋 중 하나라도 비면 GO를 주지 않는다.

## 6. 보류 기준
- 규정 준수 문장은 있는데 수치가 없으면 HOLD.
- 수치는 있는데 증빙/기한 통제가 없으면 HOLD.
- 감성어가 많아 문장이 흔들리면 HOLD.

## 7. 반려 조건
- 감성/압박 비중이 지나치게 높음.
- 수치 근거가 없음.
- 내부통제 언어 없이 단정적으로 밀어붙임.

## 8. 검수 메모 예시
- [p43][HOLD] 규정 준수 문장은 있으나 수치 근거 누락.
- [p43][DROP] 압박성 문구만 있고 내부통제 문장이 없음.

## 9. UI 확인
- 규정 준수, 수치, 통제 문장이 한 화면에 보여야 한다.
- 감성어가 과하면 발송 버튼이 보류돼야 한다.
- 회신 예상일과 추가 요청 사항이 로그에 남아야 한다.
