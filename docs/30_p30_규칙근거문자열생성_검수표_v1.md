# p30 규칙근거 문자열 생성 검수표 v1

대상 사건: 2024타경1001
법원: 서울중앙지방법원
주소: 서울시 예시구 예시동
아파트: 예시아파트
규칙근거 문자열: RA-30|2024타경1001|LTV>0.85|score=78

## 1. 이 페이지에서 보는 것
- 규칙근거 문자열이 정해진 모양으로 나오는지 확인한다.
- 사건번호와 규칙ID가 빠지지 않는지 본다.
- 아무 설명 없이 적힌 메모가 아닌지 확인한다.

## 2. 입력 필드
- 규칙근거 문자열
- 규칙ID
- 사건번호
- 점수
- 검수 메모

## 3. 판정 순서
1. 문자열에 규칙ID가 있는지 본다.
2. 사건번호가 들어 있는지 확인한다.
3. 조건과 점수가 같이 적혀 있는지 본다.
4. 표준 패턴과 맞는지 확인한다.

## 4. 통과 기준
- 표준 포맷이 유지된다.
- 사건번호와 규칙ID가 같이 남는다.
- 조건과 점수가 한 줄에 읽힌다.

## 5. 보류 기준
- 문자열은 있으나 사건번호가 비면 HOLD.
- 규칙ID는 있는데 조건이 비면 HOLD.
- 다른 사건의 문자열을 가져오면 HOLD.

## 6. 반려 기준
- 포맷이 깨지면 DROP.
- 규칙근거가 메모 수준이면 DROP.
- 표준 패턴 없이 결과만 남기면 DROP.

## 7. 샘플 판정 예시
- GO: RA-30|2024타경1001|LTV>0.85|score=78
- HOLD: 규칙ID는 있으나 사건번호가 비어 있는 경우
- DROP: "위험함" 같은 단어만 적은 경우

## 8. 기록할 것
- [p30] [GO/HOLD/DROP]
- 규칙근거 문자열
- 규칙ID
- 사건번호
- 패턴 일치 여부
- 검수자/시각

## 9. 플랫폼에서 확인할 것
- UI는 문자열 전체를 보여줘야 한다.
- 패턴이 깨지면 완료 카드로 보여주면 안 된다.
- 사건번호가 없으면 보류 카드로 내려야 한다.
