# p19 아파트명/주소 토큰 정합성 검수표 v1

대상 사건: 2024타경1001
법원: 서울중앙지방법원
주소: 서울시 예시구 예시동
아파트명: 예시아파트
주소 토큰: 예시구 / 예시동

## 1. 이 페이지에서 보는 것
- 아파트명과 주소 토큰이 같은 단지를 가리키는지 확인한다.
- 단지명이 비어 있거나 엉뚱한 주소와 붙지 않았는지 본다.
- OCR이 단지명만 따로 놓치지 않았는지 확인한다.

## 2. 입력 필드
- 아파트명
- 주소
- 주소 토큰
- 사건번호
- 법원명

## 3. 판정 순서
1. 아파트명부터 읽는다.
2. 주소에서 시군구 토큰을 뽑는다.
3. 단지명과 토큰이 같은 사건인지 확인한다.
4. 원문과 OCR이 다른 사건으로 섞이지 않았는지 본다.

## 4. 통과 기준
- 아파트명과 주소 토큰이 서로 맞는다.
- 단지명이 다른 사건과 섞이지 않는다.
- 원문과 OCR이 같은 주소를 가리킨다.

## 5. 보류 기준
- 아파트명은 있는데 주소 토큰이 잘리면 HOLD.
- 단지명은 보이지만 주소가 애매하면 HOLD.
- OCR이 단지명 일부를 놓치면 HOLD.

## 6. 반려 기준
- 아파트명 미상 상태인데 결론을 내면 DROP.
- 다른 단지명과 주소를 붙이면 DROP.
- 단지명과 토큰이 끝내 안 맞으면 DROP.

## 7. 샘플 판정 예시
- GO: 예시아파트 / 예시구 예시동 / 주소 일치
- HOLD: 단지명은 있으나 토큰이 일부 잘린 경우
- DROP: 아파트명이 공란인데 인근 단지로 넘긴 경우

## 8. 기록할 것
- [p19] [GO/HOLD/DROP]
- 아파트명
- 주소 토큰
- 정합성 결과
- 검수자/시각

## 9. 플랫폼에서 확인할 것
- UI는 아파트명과 주소 토큰을 같이 보여줘야 한다.
- 단지명이 공란이면 승인 카드로 보여주면 안 된다.
- 주소가 엇갈리면 보류로 내려야 한다.
