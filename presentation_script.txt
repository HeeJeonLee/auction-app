저희는 휴대폰에서 경매 관련 화면을 촬영·업로드하면, AI가 경매취하 후보를 분석하고 권리 위험, 대주 추천, 상담 멘트까지 자동 생성하는 MVP를 구현했습니다.

핵심은 단순한 OCR이 아니라, 실제 영업과 상담에 바로 연결되는 경매취하 후보 발굴 흐름을 만드는 것입니다.

현재 구현된 기능은 다음과 같습니다.
- 휴대폰 캡처 기반 후보 입력
- 엑셀 업로드/다운로드
- 분석 점수 및 등급 자동 계산
- 권리 요약 자동 생성
- 추천 대주 자동 분류
- 소유주 설득 멘트, 전화 상담 멘트, 현장 방문 멘트 자동 생성

이 시스템의 가치는 다음과 같습니다.
1. 수많은 사건 중 실제로 검토 가치가 높은 후보를 빠르게 선별할 수 있습니다.
2. 상담 준비 시간을 크게 줄일 수 있습니다.
3. 권리분석, 대주 매칭, 상담 대응을 한 흐름으로 관리할 수 있습니다.
4. 향후 탱크옥션 API 연동까지 확장할 수 있는 구조입니다.

즉, 이 프로젝트는 경매취하 후보를 찾는 도구이자, 영업과 상담을 더 효율적으로 진행하게 해주는 운영 시스템으로 발전 가능성이 큽니다.
