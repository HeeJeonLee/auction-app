안녕하세요.

경매취하 후보 발굴 AI MVP 개발 요청드립니다.

핵심 목표는 휴대폰에서 탱크옥션 캡처 화면을 업로드하면, AI가 사건별로 자료를 분석하고 경매취하 가능성, 권리위험, 대주 추천, 상담 멘트까지 자동 생성하는 MVP를 만드는 것입니다.

초기 범위는 다음과 같습니다.
- 휴대폰 캡처 기반 입력 방식
- 엑셀 업로드/다운로드 지원
- 후보 목록 관리
- 분석 점수/등급 자동 계산
- 권리 요약 자동 생성
- 추천 대주 자동 분류
- 소유주 설득 멘트, 전화 상담 멘트, 현장 방문 멘트 자동 생성
- 간단한 요약 통계 제공

특히 중요한 포인트는 다음과 같습니다.
1. API 없이도 사용자가 캡처 이미지를 업로드할 수 있어야 합니다.
2. 등기부 확인이 필요하다고 판단되면 추가 자료 요청 구조를 포함해야 합니다.
3. 분석 결과는 단순 OCR이 아니라 구조화된 판단 흐름으로 보여야 합니다.
4. 향후 탱크옥션 API 연동이 가능하도록 입력부와 분석부를 분리해 설계하는 것이 좋습니다.

현재는 MVP 수준으로 빠르게 구현하는 방향으로 진행 중이며, 추후 확장 가능성을 열어두는 구조로 부탁드립니다.

감사합니다.
